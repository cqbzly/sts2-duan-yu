# v0.5.13：真气无上限

真气取消9点上限，所有运气效果都可继续累积。左下角计数器只显示当前真气，卡牌费用预览与悬浮说明同步去掉“/9”。例如8气运气3后为11气，持有9气时头环在自己的回合结束后可增加到10气。

真气费用仍须在整张牌打出前足额支付；真气跨回合保留、不自然流失，战斗结束清空。头环仍为开战运气5、每个自己的回合结束运气1。其余卡牌数值、剑势8与凌波3上限不变。
