# v0.5.8：借招排除基础攻击

北冥借招与借招回锋的候选池排除所有基础稀有度（Basic）攻击，包括各角色的打击。其余已注册角色完整卡池与角色归属事件中的攻击继续等概率出现，高费、X费、有专属资源门槛的攻击，以及其他模组角色和注入角色池的攻击都保留。

北冥借招和借招回锋从其他已注册角色的完整卡池及归属于这些角色的事件牌中，等概率抽取非基础稀有度攻击牌，包含其他模组角色和注入角色池的攻击；排除全部基础稀有度（Basic）攻击，包括各角色的打击。不按费用、其他稀有度、专属资源或特殊打出条件预筛，同次生成按牌ID去重。候选数量随游戏版本与启用的模组变化。高费、X费和依赖其他角色资源的攻击都可能出现。生成牌添加消耗，固定能量费在本回合或首次打出前为0；X费、星星等其他资源费用和原生打出条件仍然生效。生成使用战斗随机数，只修改生成实例，不改写原始模板。

本次不调整卡牌数值。借力抽弃、吐纳供气过牌、踏虚减伤过牌、双脉并进取回原有已消耗剑气和一气贯之输出续手均沿用v0.5.7；七张纯伤害牌保持v0.5.5数值。卡面正文继续省略重复真气费用，专属费用标记与强制支付规则保留。4打击、4防御的10张初始牌组、玉佩开场3气和自己的回合末失去1气不变。
