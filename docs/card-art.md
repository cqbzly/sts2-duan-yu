# 段誉卡面设计

v0.1.1将86种卡牌从通用符号升级为按牌名和效果组织的原创矢量插画。卡图为1000×760像素，使用500×380设计坐标；游戏运行时将内置SVG绘制成缓存纹理，无需联网或外部图片包。

## 视觉规则

- 北冥：深青山水、玉色气流、内旋气海、经脉与百川；突出吸纳、蓄势与内功。
- 凌波：蓝色山雾、白衣身影、水纹、足迹与七星；突出位移和卸力。
- 六脉：金线与六种剑气轨迹，指尖为出招起点；少商厚重、商阳锐直、中冲扇射、关冲护弧、少冲轻捷、少泽回旋。
- 书生：暖纸色、书卷、山门、莲花与援手；表现读书、不愿伤人和护持同伴。

18类场景包括指诀、护体、气旋、步法、经脉、掌法、书卷、百川、打坐、山门、六剑、莲花、七星、援手、袖锋、震荡、梦醒和新生。每张牌有明确的场景、主题与变体映射；升级沿用该牌插画，游戏负责升级标记和数值。

源代码为`src/DuanYu/Assets/DuanYuCardArt.cs`，通过`DuanYuArt.Card()`接入现有纹理缓存。原有角色、事件、遗物图标及游戏原生费用、标题、描述界面继续使用原有入口。

## 导出与验证

```powershell
.\scripts\test-assets.ps1 -ExportArtPath artifacts/card-art
.\scripts\render-promo.ps1
```

第一条命令加载纹理和场景，并导出 PNG 与 SVG，验证尺寸及源图唯一性。第二条命令使用导出的游戏卡图生成精选画册 `assets/card-gallery.png`，并检查文字区域溢出。
