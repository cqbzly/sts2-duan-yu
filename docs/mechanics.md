# 段誉：核心机制与结算规范

设计版本0.5.1。本文件约定所有卡牌、遗物与事件共同遵循的行为；[卡牌图鉴](cards.md)给出96张牌的完整文本。当前卡池包含23张普通、38张罕见、22张稀有、5张基础、6张衍生和2张状态牌；常规奖励池共83张。真气使用独立资源，所有真气费用必须在整张牌执行前足额支付；其余平衡数值沿用v0.5.0。实战顺序见[A10 小抄](cheat-sheet.md)，已执行校验及其边界见[运行时校验说明](runtime-verification.md)。

## 1. 资源、区域与目标

| 对象 | 范围 / 归属 | 保存与清理 |
| --- | --- | --- |
| 真气 | 每名玩家独立，整数0～9；段誉在战斗界面左下角用独立的“真气”计数器和专属图标显示。 | 跨回合保留；战斗开始置0再处理起始遗物；战斗结束清空。真气不读写宿主辉星，二者互不影响。 |
| 剑势 | 每名玩家独立，整数0～8。 | 每回合开始清零；战斗开始为0，战斗结束清空。每层使六种剑气每段伤害增加1。 |
| 凌波 | 每名玩家独立，整数0～3。 | 不因结束出牌阶段立即清除；在其下一回合开始时先清除旧层数。 |
| 剑气 | DY_T01～DY_T06六种衍生攻击。 | 仅存在于当前战斗，牌的消耗与虚无按下文处理。 |
| 专属状态牌 | DY_S01气滞、DY_S02异种真气。 | 不可升级，不进入常规奖励；只由规定效果在当前战斗生成。它们不是技能，也不是剑气。 |
| 每回合记录 | 技能数、攻击数、剑气数、已打出剑式集合、成功耗气次数、凌波减伤次数。 | 从本人的回合开始累计至下一次本人回合开始；队友行动不重置。 |
| 每战记录 | 大理国印、朱蛤元息等的使用情况。 | 新战斗重置；不因换回合或能力重新生效而重置。 |

本设计以10张手牌上限为基准。普通格挡、能量、力量、敏捷、虚弱、易伤、脆弱、消耗、保留与抽牌沿用宿主游戏概念。若目标版本或其他效果改变手牌上限，生成与抽牌都使用修改后的上限。

未另行说明时，“获得”“运气”“抽牌”指打出者；单体攻击与减益由玩家选择一名存活敌人。“所有敌人”在该句执行时取得当前存活敌人集合。“选择一名存活玩家”可以选择自己，单人模式默认自己。

## 2. 真气与耗气

### 运气

**运气N：获得N点真气，最高9点。** 溢出的部分丢失，不转化成伤害、格挡、能量或下回合资源。效果写运气2，但从8升至9时，实际只获得1。真气不能为负，也不具有能量的自然刷新行为。

北冥通过技能、攻击和特定条件积气；敌人没有因此新增可被吸走的内力槽。该机制不抽走敌人行动、不减少队友资源，也不自动恢复生命。

### 真气费用

**真气费用N：出牌前必须拥有并支付N点真气，支付成功后才开始执行整张牌。** 六种剑气固定需要1点真气；其他牌按牌面显示的费用支付。

- 真气不足时整张牌不可打出，不执行基础效果或任何附加效果，也不消耗能量、不移除手牌、不登记出牌次数。
- 费用支付是强制的，没有“拒绝支付”选项；卡牌费用预览会显示真气图标和数值。
- 能量、真气与必要目标都在正文执行前检查；费用不足或目标无效时不会支付任何费用。整张牌的所有伤害、格挡、抽牌、生成牌和状态效果都建立在这次成功支付上。
- 免费打出、自动打出与复制成新牌后的出牌仍需支付真气；只免除能量费用的效果不会免除真气费用。同一次激活内的原生Replay与能量费用一致，只支付一次；独立触发的自动再次打出需要重新支付。
- 牌正文中之后获得的真气不能追溯支付本牌费用。牌结算后的返气、能力和遗物收益在本牌完成后处理。
- 气滞回合末扣气、战斗结束清空和真气溢出都不算一张牌的真气支付，也不触发“支付真气后”的能力。

### 真气与能量衔接

气海充盈支付1能量后获得1能量；涌泉引气用生命换1能量；百川归海为1费（升级0费），提供5气、1能量、2抽，升级后提供7气、2能量、2抽；三者均消耗。内力震荡为3费高伤攻击；读书明理需支付3点真气，之后抽牌并获得1能量。少泽剑气需支付1点真气，提供伤害和虚弱，不回能。获得真气本身不回能，也不递归触发真气支付奖励。万流归宗和六脉齐发使用原生X费用：先支付本牌捕获的X能量，再按该X执行正文，不因正文内的回能重新计算X；六脉齐发还必须先支付3点真气。

琅嬛玉佩只在每场战斗开始时运气3；不再提供首张技能、第三种剑气或第六种剑气的额外资源。首技能和剑式相关的回能、抽牌仍由六脉贯通、守拙等其他效果独立提供。

v0.5.0沿用上一版的攻击类型分配，同时重新收紧资源门槛。攻击即使同时生成剑气、抽牌或给格挡，也不触发首技能玉佩和凌波微步；看卡牌类型，不凭附效判断。异种真气是可打出的状态牌，同样不触发首技能。

北冥神功在每回合前两次成功支付真气后各返2气，首次另回1能量；守拙在回合开始运气3、首张实际打出的剑气结算后回1能量。六脉贯通在不同剑式首次达到3种和6种时各回能一次。多份能力叠加收益，触发次数仍共用玩家本回合记录。所有费用先支付；不能借用本牌后续回能来支付它的原始费用。

## 3. 凌波

**凌波：每当将要承受一段修正后大于0的攻击伤害，先失去1层凌波，使这段伤害减少1点，最低为0；随后处理格挡。最多3层，旧层数在你的下个回合开始时清除。**

结算位置：

1. 宿主结算力量、虚弱、易伤、其他攻击修正及其取整，得到该段将要造成的攻击伤害。
2. 若伤害为正且目标有凌波，消耗1层，固定减少1点。
3. 由目标的格挡吸收剩余伤害，再扣生命。
4. 该段完全结束后处理“因凌波减少伤害后”的收益，例如风过无痕的格挡。

凌波本身不是格挡，不受敏捷或脆弱影响。单段攻击只消耗1层；5次攻击最多消耗已有的3层；即使格挡原本足够，凌波也照常先消耗。原本就是0的攻击不消耗凌波。将1点伤害降至0也算成功减伤。

直接失去生命、毒伤、荆棘等非攻击伤害不受凌波减少。凌波不抵消攻击附带的虚弱等减益，除非宿主原本就规定该减益必须实际造成生命伤害才能施加。

Wither、Burn、Toxic 等非攻击状态伤害仍按宿主规则结算格挡；它们不触发凌波、不消耗凌波层数，也不触发依赖凌波减伤的收益。直接失去生命另按原效果处理，不能把所有非攻击伤害理解成无视格挡。该边界已纳入原生伤害回归检查。

凌波不会在你点击结束回合时消失，因此可以用于敌方行动。回合开始清除旧凌波后，新产生的凌波保留。例如易经心法在新回合给予的凌波不能被同一次清理删除。

## 4. 六种剑气

“剑气”是严格的卡牌身份集合：DY_T01少商、DY_T02商阳、DY_T03中冲、DY_T04关冲、DY_T05少冲、DY_T06少泽。升级与复制不改变身份。图鉴的“北冥／凌波／六脉／通用”标签只是构筑分类；生成剑气的攻击或技能不因此成为剑气，借来的原生攻击也不属于六剑。

### 获得、生成与升级

- 六剑全部是0费攻击，消耗、虚无；不进入普通奖励、商店卡牌、战斗外随机变牌或永久牌组。每次发动都必须支付1点真气。
- 没有写“升级版本”或“+”时，生成未升级剑气。生成器升级不自动升级产物，必须以升级后的完整文本为准。
- 需要随机生成时，使用战斗卡牌生成 RNG 从六种中无放回抽取；同一次生成多个剑式时不重复，生成结果不打开选择界面。
- “六种各1张”仍保证六种各一张，但加入顺序由战斗 RNG 随机打乱。
- 生成时手牌已满，新牌进入弃牌堆；抽牌时手牌已满，停止继续抽取，剩余牌留在抽牌堆。空抽牌堆时按宿主洗回弃牌堆的规则补充。
- 虚无只在回合末消耗仍位于手牌中的牌；满手溢出到弃牌堆的剑气不会被跨区域清理。主动消耗剑气则直接进入消耗堆，不能当成弃牌保存到下一轮。
- 同时拥有保留和虚无的牌，虚无优先；乾坤步不能救下手中的剑气。临时“本回合保留”只跳过本次正常弃牌，不让牌永久保留。
- 剑气最多升级一次，重复升级不叠加。剑气归宗只升级当时实际在手中的剑气，不能升级因满手刚刚进入弃牌堆的少商剑气。

### 生成不等于打出

生成、抽到、复制卡牌对象、从消耗堆取回，都不触发“打出剑气”。六张剑气分别打出时是六次攻击事件；中冲对多个敌人伤害只算一次打出。

独立触发的自动再次打出是一轮新的卡牌激活，重新检查并支付真气、检查目标与登记计数；若外部效果免除能量费用，不因此免除真气。同一次激活的原生Replay只支付一次真气，重复正文各自登记实际出牌次数；仅重复一个伤害效果不制造新的打牌事件。复制卡牌对象继承其升级状态，能力触发不因复制动作本身发放。

### 剑势

每张剑气实际完成本次结算后，获得1层剑势。每回合首次打出第3种不同剑气时额外获得1层，第6种时额外获得1层；两个门槛每回合各一次。升级版与未升级版共用剑式身份，重复剑式不会再次跨过门槛。每次增加都受8层上限限制，超出部分丢失；回合开始时剑势清零。

剑势只增加六种剑气的伤害，每层为每段伤害加1；普通攻击、格挡和减益层数不受影响。少商、中冲的第二段伤害同样享受加成，中冲每个敌人的每段分别计算。当前剑的所有伤害完成后才获得本次新增层数，不能把剑后成长用于同次结算的第二段。

从0层开始，本回合依次打出六种不同剑气，各次结算后的层数为1、2、4、5、6、8；六张牌分别使用打出前的0、1、2、4、5、6层伤害加成。Replay 每次真实再次打出并结算都获得1层，后一次使用前一次已获得的层数；重复同剑式不重复获得第三/第六种奖励。只生成、复制卡牌对象或重复单个伤害效果不增加剑势。

书生意气、大梦初醒与异种真气的固定剑势收益直接增加层数，受同一上限限制；不计为打出剑气，不增加剑式数量，也不触发玉佩或六脉贯通的剑式奖励。

| 回风取物 | 1费、消耗；从弃牌堆选择1张牌加入手牌；弃牌堆为空时改为抽1/2张。之后运气1。 |
| 琅嬛寻卷 | 1费、消耗；从抽牌堆选择1张非状态牌加入手牌，运气2/3。 |
| 经脉归一 | 3费能力；打出时及每回合开始将1张异种真气加入手牌；每回合前2次消耗状态牌后，获得5/7格挡、运气1并随机加入1张未升级剑气。 |

“消耗其他手牌”与牌自身的“消耗”关键词是两件事。生生不息和逆运经脉没有自耗关键词，仍然能主动清牌；已消耗、已离手或被其他效果阻止消耗的牌，不计入本次按张收益。生生不息先处理原手牌快照，再生成剑气，不把本次新生成的剑继续投进同一次消耗。

## 5. 一次打牌的顺序

1. 检查能量、真气、必要目标与合法性。不足费用或目标无效时取消出牌，牌留在手中且不扣费用。足额支付本次能量与真气后才继续，锁定原目标并将牌移出手牌。
2. 登记本次实际打出：所属玩家的技能／攻击／剑气次数和剑式集合增加。记录该牌在各计数中的序号。
3. 按正文顺序执行效果。多段伤害分别结算力量等修正；真气费用已在本步骤前完整支付，本次正文完成后处理“支付真气后”的能力收益。
4. 处理该牌正文结算后的收益：先按取得顺序处理遗物，再按能力生效顺序处理能力。此时该牌仍在宿主的出牌区域；新安装的能力已经生效，但使用出牌前快照，不对自己这次打牌追溯触发。
5. 本次打牌的全部重复执行完成后，由宿主按关键词将牌移至消耗堆或弃牌堆，能力牌离开出牌区域。若存在Replay，每次重复执行各自登记次数、结算正文并触发卡后收益，最终只进行一次区域转移。

这个顺序对应目标游戏版本的`CardModel.OnPlayWrapper`：正文→`AfterCardPlayed`→最终移牌。因此卡后抽牌不能在同一次洗牌中抽回仍处于出牌区域的本牌；它也尚未成为可从弃牌堆或消耗堆选择的目标。原始设计稿中先移牌再触发卡后收益的顺序已据此修正，避免替换宿主整个打牌流程。

同一时点的多个效果使用稳定的取得／生效顺序，不依赖动画速度。联机由权威事件队列排序，客户端只能展示已确认的结果。

若打出时要求一个敌人或存活玩家，但目标在支付前已经无效，取消出牌且不支付。支付后目标死亡或失效时，该目标对应效果跳过，其他句子继续；不自动重选目标。玩家自身死亡时终止其尚未执行的本张牌效果及收益，因此舍身相护可能在生命不足时无法提供保护。整场战斗结束时终止所有余下动作，不继续抽牌、返气或触发奖励。

剑随心转直接随机生成两种不同剑气，不需要选择已有剑气作为目标。内息归元的“至多”允许选择0张。逆运经脉有合法其他手牌时选择1张；生生不息按当前其他手牌整体结算，不再从消耗堆取回卡牌。

## 6. 计数、叠加与能力

所有“每回合前N张／前N次／首次第3种或第6种”的判断使用从本人回合起点累计的记录，包含能力打出之前发生的行为。获得能力不重置记录、不补发过去收益。例如已经打过2张技能才打出凌波微步，本回合后续技能不会获得它的前2张奖励。

同名能力叠加数值，不叠加次数上限；不同名字的能力独立结算。例：两层北冥神功使本回合前2次成功耗气各返4真气，且首次额外获得2能量；两层未升级指法纯熟使前2张剑气伤害各增加6，而不是前4张增加3。升级与未升级版本共用同一身份，各自的数值相加。

| 能力 | 计数或读取时点 |
| --- | --- |
| 北冥初成 / 北冥神功 | 当回合成功支付真气的序号；本牌正文完成后抽牌／返气，神功在首次时再回能。同一次激活的Replay不重复支付，也不重复触发这项支付收益。北冥初成打出时运气2属于正文。 |
| 凌波微步 | 该技能打出时登记的技能序号；该牌结算后获得凌波。 |
| 指法纯熟 / 无相之境 | 当前剑气的打出序号；前者影响本牌攻击，后者在本牌结算后给格挡。 |
| 六脉贯通 | 剑式集合第一次由2种变3种、由5种变6种的那张牌；两个阈值各结算一次，重复剑式不补发。 |
| 风过无痕 | 本回合第一次实际发生凌波减伤；格挡在该段生命结算之后获得。 |
| 真气护体 | 自身回合结束效果执行时的真气；先向下取整一半，再加升级固定值。 |
| 百脉归炉 | 自身任意牌实际进入消耗堆时，按每张2/3格挡触发；消耗气滞或异种真气时额外运气1，不读取当回合攻击数。 |
| 守拙 | 每回合开始运气3；本回合首张剑气结算后获得1能量。 |
| 易经心法 / 无形剑阵 | 心法打出时立即获得8/12格挡，之后每回合开始再获得；剑阵打出时选2种不同剑气各1张，之后每回合开始选1种。升级剑阵在两种时点均生成升级剑气。 |

剑势、凝气成锋与指法纯熟的固定伤害加成在力量所在的基础伤害加法阶段加入，再应用虚弱／易伤等修正。中冲对每个敌人的每段伤害都可获得该加成；不会因目标数量而额外增加出牌次数或剑势成长。凝气成锋多次打出的数值相加，在本回合结束时清除；剑势在下一回合开始时清零。

多次独立“获得格挡”各自应用宿主的敏捷／脆弱修正。援手、同行、舍身相护的格挡使用接收者的这些修正；施术者不把自己的敏捷转移给队友。凌波始终为固定减1。

## 7. 回合边界

本节只约定新增效果的顺序，不要求替换宿主全部回合系统。实现必须将新效果挂在能达到下述结果的宿主时点。

**自身回合开始：** 先快照上一回合记录供枯荣禅珠使用，再清除旧凌波并重置本回合计数。新的回合开始格挡必须在宿主清理旧格挡之后授予，不能立刻被删掉。随后按“已排队的下回合效果 → 遗物 → 能力”的顺序处理本设计的回合开始效果，同类按生成／取得顺序。此窗口在基础抽牌前执行；倒踩七星的额外抽牌与基础抽牌分别处理，均遵守手牌上限。

**自身回合结束：** 按宿主时点处理真气护体等回合结束能力及手牌效果。气滞在手牌回合末钩子先扣2真气，再按原生虚无消耗；主动消耗后的气滞已经不在手中，不再扣气。保留、虚无与正常弃牌沿用宿主规则，清除仅限本回合的剑气伤害加成。真气跨回合保留；剑势与凌波在自身下回合开始时清零；战斗结束清空全部角色资源。

能力顺序是有意义的：守拙在回合开始提供的真气会影响随后易经心法的凌波条件；顺序相反时不能追溯补发凌波。界面应按实际顺序显示能力，战斗日志展示每次读取的真气。

延迟效果逐个保存，不覆盖：两张以退为进会在下回合各运气2；多次倒踩七星各额外抽1。战斗结束移除未触发的延迟效果，不带入下一战。

## 8. 多人模式

真气、剑势、技能数、剑气身份集合和触发次数全按所属玩家隔离。多名段誉各自管理自己的资源；队友打牌不能帮你叠剑势、凑六脉贯通，也不能用你的气。

共享玩家阶段中，每名角色只在其阶段起点重置一次计数。一个玩家结束行动、队友继续行动，不开启新的个人回合。支援牌可以选择仍存活且已经结束行动的队友；其抽到的牌不会自动重新开放行动，是否还能出牌遵循宿主规则。凌波仍持续至该接收者的下一回合开始。

同时出牌按权威队列锁定目标与资源：若确认时目标合法，随后队友击杀该敌人，按目标失效规则跳过对应效果。由本牌伤害导致的击杀才能触发留三分力；队友击杀或随后毒伤击杀不算。

本版有3张明确支援牌：援手、同行、舍身相护。其余默认作用于自己或敌人。专属事件的资源与奖励归属见[遗物与事件](relics-and-events.md)。
