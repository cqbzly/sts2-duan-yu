# v0.3.0：北冥炼化与借招

v0.3.0 开发预览版，回应攻击牌偏少、输出保守、资源收益随机以及缺少主动清理状态牌的反馈。版本下载见 [GitHub v0.3.0](https://github.com/cqbzly/sts2-duan-yu/releases/tag/v0.3.0)；[Steam工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3841781260)沿用 private 可见性。完整文本见[88张卡牌图鉴](../cards.md)，操作见[A10 小抄](../cheat-sheet.md)。

## 攻击与固定资源

- 常规75张牌中的攻击由18张增加到32张。14张原技能先造成伤害并保留原附效；攻击类型不再触发玉佩首技能或凌波微步。
- 打击伤害10/14，无意一指每段16/22；以气催劲每段22/30；一气贯之改为1费，每段14/20，耗气成功后增加第三段。
- 蓄势一击改为1费，造成24/32加当前真气×4的伤害，不扣真气，随后向弃牌堆加入气滞。天南一指基础28/38，耗气5追加70/90；内力震荡的耗气附伤改为全体35/45。
- 书生意气保持抽2/3、至少5气额外抽1，然后固定获得2/3气、1能量、2/3剑势。大梦初醒保持清空格挡、抽3/4，然后固定获得4/6气、2能量、4/6剑势。
- 随机性集中在招式身份：剑随心转生成2种不同剑，北冥借招生成2种不同外门攻击，生生不息生成可重复的随机剑；抽牌与资源量不再随机。

## 主动消耗与状态

| 卡牌 | 新效果 |
| --- | --- |
| 逆运经脉 | 选耗1张其他手牌，固定抽3/4、运气2/3；本牌不自耗。 |
| 内息归元 | 0费、自耗，选耗至多3/4张其他手牌；每张实际消耗运气1、获得4/6格挡。 |
| 生生不息 | 1费获得8/12格挡，消耗所有其他手牌，按实际数量随机生成等量剑气，可重复；升级生成升级剑，本牌不自耗。 |
| 百脉归炉 | 由不争之心改造的1费能力，每消耗1张牌获得3/4格挡。 |
| 不染尘 | 原清虚弱、脆弱、中毒及8格挡后，再消耗手中所有状态牌；每张实际消耗运气2、抽1。 |
| 气滞 | 不可打出、虚无；回合末仍在手中时扣2气再消耗，扣气不算发动耗气。 |
| 异种真气 | 1费状态：运气3、剑势2、抽1、消耗；不计技能。 |

两种状态均不可升级、不进常规奖励。生生不息的主动整手消耗与自身是否带“消耗”是两件事：先打要用的核心，再用它把状态和余牌换成剑；它本身保留在战斗循环中。面对沙漏的状态污染，也可用罕见牌逆运经脉或内息归元开始清理，无需先拿齐稀有牌。

## 跨角色借招

北冥借招替代冥想入定，1费、消耗，从原生白名单无放回生成2种攻击，本回合0费并赋予实例消耗；升级版生成升级牌，随后向弃牌堆加入异种真气。不修改原生模板，不将借来的攻击视为六脉剑气。

白名单为铁卫 `Bash`、`IronWave`、`PommelStrike`、`TwinStrike`，静默 `DaggerSpray`、`DaggerThrow`、`Slice`、`PoisonedStab`，故障机器人 `BeamCell`、`GoForTheEyes`、`SweepingBeam`、`RipAndTear`。这些攻击不依赖星星、奥斯蒂或充能球资源；临时费用沿用宿主规则。

## 资源与文档

卡牌总数86→88；图鉴增加专属状态类别，明确不可升级；数据校验允许气滞费用-1并验证剑气/状态生成引用。资源初始化、加载检查和画廊导出覆盖两张新状态，新增经脉闭塞与异种真气插画，并更新借招和归炉场景。
