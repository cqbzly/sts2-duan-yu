# v0.4.0 再平衡发布版

v0.4.0 是段誉模组的再平衡版本。它针对上一版实战中凌波、剑势和六剑资源闭环过强的问题收紧机制。

## 机制调整

- 凌波每层只使一段攻击伤害降低 1 点，最多 3 层，并在段誉下回合开始时清除。
- 剑势上限为 8，每回合开始清零；每张剑气结算后获得 1 层，第 3 种和第 6 种不同剑气各额外获得 1 层。
- 六种剑气均需至少 1 点真气才能打出，并在发动时支付 1 点；剑气不再自带真气、能量或运气收益。
- 剑气生成使用战斗 RNG 无放回随机抽取；双脉并进为 2 费并随机生成两种不同剑气。
- 书生意气、大梦初醒、六脉神剑、蓄势一击和主动消耗牌的费用或收益下调。

## 验证边界

本版本已完成 `node scripts/validate.mjs`、规则测试、引擎自测、资源测试和完整 A10 多种子采样：20局中6胜、14负、0异常，胜率30.0%。旧版 v0.3.0 的单种子通关记录保留为历史基线，不用于推断 v0.4.0 玩家胜率。

发布包包含 Release DLL、0.4.0 清单、安装说明和通关小抄；工坊工作区只包含 Release DLL、清单和封面图。
