# 段誉：构筑指南与平衡验证

版本 v0.5.35。常规奖励池共83张，普通23张、罕见38张、稀有22张。另有5张基础、1张先古、6张衍生和2张状态牌。本页的 A10 通关示例来自旧版本单个种子。[卡牌图鉴](cards.md) · [A10 实战小抄](cheat-sheet.md)

## 基础循环

真气无上限，跨回合保留，不自然流失；气滞仍在手牌回合末失去2气。凌波无叠层上限，每层持续使本回合每段伤害减少1点，受伤不消耗层数，自己的下回合开始清除；明确失去生命的效果不减免。六种剑气均为0费、消耗、虚无，通常需1点真气；经脉归一生成的剑气免费。三条路线共用这些组件，选牌应解决当前缺口，不要求从开局只走一个标签。

剑势上限8，每回合开始清零，每层使六种剑气和六脉齐发的每段伤害增加1。每张剑气结算后加1层，每回合第3种和第6种不同剑气各额外加1层。

琅嬛玉佩在战斗开始运气3。守拙每回合开始运气2，首张剑气结算后回1能量。六脉贯通在当回合打出第3种和第6种不同剑式后提供额外收益。

角色的资源回路需要同时有产气、可付费用、可打手牌和有效输出。持续加气却不转化为输出或防守，会拖慢战斗；反复抽牌却没有能量也无法解决敌人。优先建立能在当前战斗兑现的组件，再补长期能力。

## 攻击不再只是等待六剑

无意一指为1费、2气，一次造成16/22伤害；以气催劲为1费、3气，一次造成27/37伤害；一气贯之为1费、3气，造成16/22伤害后抽2张。真气不足时这三张都不能打出。指风为1费全体9/12；内力震荡为3费、3气，对目标造成48/64伤害，对其他敌人造成20/26伤害。六脉齐发为0能量、真气X费，对一个敌人造成6/8点剑气伤害X次。剑势等增伤逐段生效。

少商起势、商阳点穴、关冲护体、中冲破阵、少冲探路、少泽回环等生成器现在先造成伤害，再保留原有附效。它们属于攻击，不再为玉佩或凌波微步提供技能次数。先用北冥初窥、书生意气、逆运经脉等真正技能启动资源，再决定要留多少真气给高伤攻击；不能继续按旧版“所有生成器都返1能”算账。

## 北冥蓄势

用技能和攻击供气。把真气留给回合末的真气护体，或先支付真气换取眼前的伤害与格挡。

| 任务 | 可用组件 | 抓牌判断 |
| --- | --- | --- |
| 早期供气与输出 | 北冥初窥、吐纳、吸纳、无意一指 | 开局已有供气与耗气出口；吐纳抽1/2张后运气2，无意一指负责把气兑现成伤害。 |
| 过滤与续手 | 借力、读书明理、一气贯之 | 读书明理零费抽3/4张并加入气滞，适合有状态清理的牌组。 |
| 能量加速 | 气海充盈、涌泉引气、百川归海、以退为进 | 前三张当回合提供能量，以退为进在下回合提供1点能量。 |
| 资源兑现 | 以气催劲、内力震荡、天南一指 | 天南一指耗气5。先算高伤攻击能否少让敌人行动一轮。 |
| 持续衔接 | 北冥初成、北冥神功 | 在满足支付条件前打出能力。 |
| 保命 | 抱元守一、纳百川、真气护体 | 真气护体读取回合结束时的真气。升级版额外提供2点格挡。 |

北冥神功费用1，升级后0。仅每回合第2次成功支付真气后运气1并获得1能量。蓄势一击为1费，造成14/19点伤害并向手牌加入异种真气。留出1点能量可以接着打出异种真气，也可以把它留给主动消耗牌。

## 凌波游身

**目标：** 用凌波处理多段攻击，用实际格挡处理大伤害与可被格挡的状态伤害，再用少量强攻击尽快收尾。

| 任务 | 可用组件 | 抓牌判断 |
| --- | --- | --- |
| 当回合防守 | 侧身避敌、抱元守一、关冲护体、临风独立 | 侧身避敌用0费补2/3点格挡和1/2层凌波。面对重击，再用高格挡牌吸收剩余伤害。 |
| 跨回合减伤 | 掠影步、倒踩七星 | 掠影步当前和下回合各给1层凌波，即时格挡更多。倒踩七星下回合多抽1张。 |
| 降低敌方输出 | 绵掌、斜行避势、少泽剑气、慈悲为怀 | 根据敌人的攻击目标与段数分配虚弱。 |
| 跨轮准备 | 踏虚而行、以退为进、倒踩七星、先退半步、易经心法 | 踏虚而行准备下回合的2张额外手牌。以退为进挡住本回合的伤害，下回合多1点能量。 |
| 结束战斗 | 回身一指、以气催劲、指风、生成的剑气 | 回身一指兼顾伤害和凌波。同回合已有凌波时还能补格挡。 |

Burn、Toxic、Wither等可格挡状态伤害与反伤也受到凌波减免；毒、卡牌生命代价等明确失去生命的效果不减免。敌人意图没有攻击，也要检查状态牌与持续伤害，保留必要的清理手段。

## 六脉变招

**目标：** 根据敌人和手牌安排随机剑式，先铺增伤与易伤，再把六剑的伤害、防御和抽牌串起来；六剑本身不返气或回能。

| 任务 | 可用组件 | 抓牌判断 |
| --- | --- | --- |
| 随机补剑 | 记诵剑谱、剑随心转、三脉同鸣 | 剑随心转优先补本回合未打过的剑式，方便接上六脉贯通。 |
| 回收剑式 | 双脉并进 | 1费（升级0费），从消耗堆取回至多2张已升级的剑气。经脉归一+生成的剑气取回后仍可免费打出。 |
| 整套六剑 | 六脉神剑 | 基础/升级均2费，不耗真气；分别给8/11格挡，并随机生成未升级/升级六剑。 |
| 持续生成 | 无形剑阵 | 1费能力；打出时随机生成1张剑气，之后每回合开始再随机生成1张；升级生成升级剑气。注意回合开始手牌空间。 |
| 伤害提高 | 凝气成锋、指法纯熟 | 先打增伤牌，再打剑气或六脉齐发。指法纯熟每段增加2/3伤害，无次数限制。 |
| 当回合成长 | 剑势、书生意气、大梦初醒、异种真气 | 先打出有用剑气积累层数；剑势回合开始清零，固定收益受8层上限限制。 |
| 回能与抽牌 | 守拙、六脉贯通、少冲剑气 | 守拙在首张剑气结算后回能，六脉贯通按第3种和第6种剑式触发，少冲剑气补抽牌。 |
| 剑气防守 | 关冲剑气、无相之境 | 关冲提供一次格挡，无相之境在每回合前3张剑气结算后各获得4/6格挡。 |

六脉神剑升级会把整套产物升级，是有稳定供气后优先考虑的升级。基础神剑与升级神剑仍需留出六张手牌空间，产物则各需1点真气；不能只看总收益，不看满手会丢到弃牌堆的那几张剑。

面对高出牌次数惩罚和反伤，六剑是六次独立攻击；不要因为零费就机械打完。状态、敌人意图和击杀条件变化后，应重新决定是否继续。

## 固定资源与随机招式

书生意气两版均为1费，先抽2/3张，当前至少5气时再抽1，然后运气1、获得1层剑势。额外抽牌在运气前判定。凝气成锋在本回合为每段剑气伤害加2/3点，指法纯熟在本场战斗为每段加2/3点。两者都适用于六种剑气和六脉齐发。

大梦初醒0费、消耗，先失去全部格挡并抽2/3张，再运气2/3、获得2/3能量和2/3剑势。优先在尚未建立格挡时使用。

剑随心转优先从本回合没用过的剑式中生成两张不同剑气。北冥借招从外门攻击中直接抽两张不同的牌，借招回锋从三张中选一张。生生不息按实际消耗张数生成随机剑气，允许同式重复。

## 北冥炼化与借招

这条路线用主动消耗换取下一步行动，处理状态牌时尤其有价值。它从罕见牌逆运经脉、内息归元就能开始，不要求先拿齐金卡。百脉归炉每耗一张给2/3格挡，消耗气滞或异种真气时额外运气1，把主动清理、剑气自耗与虚无消耗连成防守和回气；技能、攻击和状态牌的消耗都可以贡献，但同一张牌实际消耗一次才计一次。

| 缺口 | 组件 | 具体打法 |
| --- | --- | --- |
| 一张状态堵住循环 | 逆运经脉 | 1费选耗1张，抽2/3张。消耗状态牌时多抽1张并运气1。 |
| 多张废牌与当前来伤 | 内息归元 | 1费选耗至多3/4张；每张运气1、格挡2/3，本牌自耗。先保留必要的攻击与防守。 |
| 整手状态或残余废牌 | 生生不息 | 先打出当前要用的核心，再花2费获得6/8格挡，消耗全部其他手牌并转成等量随机剑气；本牌可循环。 |
| 多种状态混入抽牌 | 不染尘 | 清除脆弱、虚弱和易伤并获得7格挡，再消耗手中所有状态牌，每张运气1并抽1张牌。保留普通好牌。 |
| 缺少当回合攻击 | 北冥借招 / 借招回锋 | 北冥借招用1费直接拿2招。借招回锋用2费先造成12/17点伤害，再从3招中选1张，并把异种真气加入手牌。两张牌都保留外门攻击的原有关键词，本回合固定能量费归零。X费和其他资源费用照常支付。 |
| 状态转化成当前行动 | 万流归宗 | X费一次获得4/6×X点格挡；按手牌顺序消耗至多X张状态，每张返1能量并运气1；不能用返还的能量重新计算X。 |
| 精确取回关键牌 | 回风取物 / 琅嬛寻卷 | 两者均1费消耗；前者从弃牌堆选择1张牌，后者从抽牌堆选择1张非状态牌。先取关键供气、格挡或攻击，再决定后续消耗。 |
| 持续状态燃料 | 经脉归一 | 3费能力，打出时及每回合开始加入异种真气；每回合前2次消耗状态牌后获得5/7格挡、运气1，并随机加入1张可免费打出的剑气。升级后生成升级剑气。 |

面对沙漏及 Wither 一类状态，先确认牌的原生回合末规则。需要使用的能力、供气或防守先打，再用生生不息换掉剩余手牌，避免把关键牌一起炼掉；只想清状态时用不染尘更精确。主动消耗能移除状态牌的后续手牌结算，单纯“这张牌自带消耗”不能替代清掉其他状态。可格挡的状态伤害也能被凌波减免，明确失去生命的效果仍需提前处理。

读书明理、逆脉强攻、借隙回身将气滞加入手牌。气滞留在手中时，回合结束先扣2气，再按虚无消耗。北冥借招将异种真气加入弃牌堆，蓄势一击、借招回锋与经脉归一直接加入手牌。异种真气花1能量，换取2气、1剑势、抽1张牌，打出后消耗。两种状态牌都能作为主动消耗素材。

## 精简与混合

起手的基础牌先保留能撑过眼前路线的部分。已有更强输出后移除打击，已有稳定格挡后移除防御；不能先删尽防守，再期待奖励补齐。重复过渡牌会稀释神功、剑阵或抽牌核心，但牌数本身不是胜负标准。

北冥路线不能再依赖少泽剑气回能：当前六剑只提供伤害、减益、抽牌和关冲格挡。记诵剑谱与其他生成器的剑式由随机结果决定；凌波路线能用商阳、少商结束战斗；六脉路线仍需要吐纳、抱元守一这类独立有价值的技能。跨路线的单卡先看是否改善当前轮次，再看标签是否一致。

## 历史证据与持续检查

以下完整通关和测试数字来自 **v0.2.1/v0.3.0** 的自动策略与固定种子。

v0.2.1 在游戏0.113.1 public-beta、BaseLib 3.4.8下，用 headless 原生流程自动策略完成 Standard A10。首个种子 `DUANYUFULLA10-001` 即胜后停止搜索；在新进程从头运行同一种子再次胜利，四首领、最终状态与决策记录一致。这是一个种子的成功与复现，不能据此计算独立样本胜率。

| 首领 | 楼层 | 战后生命 |
| --- | --- | --- |
| Vantom | 17 | 68 |
| Kaiser Crab | 33 | 80 |
| Queen | 48 | 77 |
| Test Subject | 49 | 77 |

原生地图、旅行、商店、休息、事件、奖励和敌方回合均参与流程，A10难度与随机遗物正常生效；未追加属性、强制奖励或读档重试。两次均完成原生结局，`nativeEnded=true`、`winTime=8`、`remainingVictoryOptions=0`。最终首领战后生命为77/83；结局事件之后快照的0生命不代表战斗死亡。当时规则23/23、引擎235/235、资源116/116和86种卡牌数据校验通过。

通关构筑先用绵掌、探穴与基础耗气牌渡过第一幕，取得易经心法后建立持续格挡；第一首领奖励拿到六脉神剑，第二幕优先升级神剑与心法，第三幕补凌波微步、双脉并进、剑随心转与指法纯熟。最终32张牌包含2打击、4防御，并没有北冥神功或百川归海。这个例子说明混合构筑可以运作，不能证明32张是最佳牌数，或所有种子都能获得同样的核心。

本局也受益于原生Orobas事件的神剑附魔、磨刀石、准备背包、钢笔尖等随机收益，以及实际消耗的药水。最终首领第五回合用已积累的8层剑势衔接升级六剑，打到12层封顶；第二幕首领和最终首领战均保持入场生命。应把生成、持续格挡、虚弱、易伤、升级和遗物视作共同作用的结果，下一步仍需要多个独立种子和人工试玩评估强度。

已完成的旧版 v0.2.0 `v020-fullrun6` 记录100局全部失败，最远在击败第三幕第一首领后败于第二首领。该记录促使本版重新检查启动能量、六剑兑现、连续首领保血和出牌顺序；不能把旧版自动策略结果当作 v0.2.1 玩家胜率。

后续平衡与持续回归重点：

- 玉佩是否只在战斗开始提供3真气，且不参与后续首技能、第三剑式和第六剑式奖励。
- 北冥神功的返气与回能、剑气抽牌和主动消耗组合是否出现非预期循环。
- 六脉神剑升级后的整套收益是否让其他稀有牌失去选择价值。
- 剑势每回合清零、群体伤害、Replay 与资源牌直接加层是否都遵守8层上限和每回合剑式门槛。
- 全程生命损失、卡牌升级与移除、药水使用、关键能力启动回合，以及第三幕连续首领的资源余量。
- 非攻击状态伤害、重复打出、同式升级与满手生成是否保持规则一致。
- 气滞扣气不计耗气，异种真气不计技能；主动消耗按实际成功张数计收益，不误耗本次新生成的剑。
- 14张改型攻击的目标、伤害与原有附效，以及北冥借招的全角色攻击池、临时费用、原有关键词和升级是否一致。
