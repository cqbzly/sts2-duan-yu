# v0.5.14：能力与剑气调整

本版调整守拙、六脉齐发、无相之境、北冥神功与临风独立。

| 卡牌 | 基础 / 升级效果 |
| --- | --- |
| 北冥神功 | 1/0费；仅每回合第2次成功支付真气后，运气1并获得1能量。 |
| 守拙 | 2/1费；回合开始运气1，首张剑气结算后获得1能量。 |
| 无相之境 | 每张剑气结算后获得2/3格挡，不再只触发前3张。 |
| 临风独立 | 1费、消耗；获得8/10格挡及2/3层凌波。 |
| 六脉齐发 | 0能量、真气X费、消耗；支付全部当前真气，对单体一次造成6/8×X点基础伤害。 |

六脉齐发的X记录本次实际支付的真气，不受化学物X影响，后续返气不计入X；同次原生重放复用X、不重复支付。X=0时可打出，但不造成伤害，不登记真气支付，也不触发支付收益。北冥神功的第1次与第3次以后支付均无收益，多份能力叠加数量，共用每回合第2次门槛。

真气仍无上限，跨回合保留、不自然流失，战斗结束清空；真气费用仍须在整张牌打出前足额支付。头环仍为开战运气5、每个自己的回合结束运气1。剑势上限8、凌波上限3。
