# 段誉：核心机制与结算规范

设计版本0.1.0。本文件约定所有卡牌、遗物与事件共同遵循的行为；[卡牌图鉴](cards.md)给出每张牌的完整文本。角色程序已按此契约接入目标游戏版本，已完成的自动校验及其边界见[运行时校验说明](runtime-verification.md)。

## 1. 资源、区域与目标

| 对象 | 范围 / 归属 | 保存与清理 |
| --- | --- | --- |
| 真气 | 每名玩家独立，整数0～9。 | 跨回合保留；战斗开始置0再处理起始遗物；战斗结束清空。 |
| 凌波 | 每名玩家独立，整数0～3。 | 不因结束出牌阶段立即清除；在其下一回合开始时先清除旧层数。 |
| 剑气 | DY_T01～DY_T06六种衍生攻击。 | 仅存在于当前战斗，牌的消耗与虚无按下文处理。 |
| 每回合记录 | 技能数、攻击数、剑气数、已打出剑式集合、成功耗气次数、凌波减伤次数。 | 从本人的回合开始累计至下一次本人回合开始；队友行动不重置。 |
| 每战记录 | 大理国印、朱蛤元息等的使用情况。 | 新战斗重置；不因换回合或能力重新生效而重置。 |

本设计以10张手牌上限为基准。普通格挡、能量、力量、敏捷、虚弱、易伤、脆弱、消耗、保留与抽牌沿用宿主游戏概念。若目标版本或其他效果改变手牌上限，生成与抽牌都使用修改后的上限。

未另行说明时，“获得”“运气”“抽牌”指打出者；单体攻击与减益由玩家选择一名存活敌人。“所有敌人”在该句执行时取得当前存活敌人集合。“选择一名存活玩家”可以选择自己，单人模式默认自己。

## 2. 真气与耗气

### 运气

**运气N：获得N点真气，最高9点。** 溢出的部分丢失，不转化成伤害、格挡、能量或下回合资源。效果写运气2，但从8升至9时，实际只获得1。真气不能为负，也不具有能量的自然刷新行为。

北冥通过技能、攻击和特定条件积气；敌人没有因此新增可被吸走的内力槽。该机制不抽走敌人行动、不减少队友资源，也不自动恢复生命。

### 耗气

**耗气N：在结算到该句时，若拥有至少N真气，自动支付N真气并执行冒号后的附加效果；否则跳过该附加效果。**

- 真气不足不妨碍打牌，也不退还能量；此前的基础效果正常执行。
- 满足条件时必须支付。没有额外的“拒绝耗气”弹窗；玩家通过出牌与顺序管理支出。
- 同一张牌最多有一条耗气语句。消耗、虚无等牌自身关键词不在耗气条件范围内；例如扣脉即使没有气可花，也仍然消耗。
- 本文的“发动耗气效果”只指成功支付正数真气并进入附加效果。支付失败、战斗结束清空和运气溢出不算。
- 先运气再耗气的牌可以使用刚获得的真气；牌结算后的遗物运气不能追溯补足此前的条件。
- “耗气后”的能力收益在该条附加效果结算后处理。实际支付数与支付后的真气立即记录；之后的返气不能取消“大理国印”已经满足的清空条件。
- 若附加伤害的原目标已死亡而战斗尚未结束，仍按正文支付真气，但不重新选敌人；该单体伤害无效。群体伤害仍可以作用于其他存活敌人。

卡牌预览应显示预计支付与剩余真气，例如“耗气6：可发动，8→2”；资源不足时显示“当前4/需要6，附加效果不执行”。若牌内抽牌等其他效果使结果不确定，预览不得伪装成确定值。

## 3. 凌波

**凌波：每当将要承受一段修正后大于0的攻击伤害，先失去1层凌波，使这段伤害减少3点，最低为0；随后处理格挡。最多3层，旧层数在你的下个回合开始时清除。**

结算位置：

1. 宿主结算力量、虚弱、易伤、其他攻击修正及其取整，得到该段将要造成的攻击伤害。
2. 若伤害为正且目标有凌波，消耗1层，固定减少3点。
3. 由目标的格挡吸收剩余伤害，再扣生命。
4. 该段完全结束后处理“因凌波减少伤害后”的收益，例如风过无痕的格挡。

凌波本身不是格挡，不受敏捷或脆弱影响。单段攻击只消耗1层；5次攻击最多消耗已有的3层；即使格挡原本足够，凌波也照常先消耗。原本就是0的攻击不消耗凌波。将1点伤害降至0也算成功减伤。

直接失去生命、毒伤、荆棘等非攻击伤害不受凌波减少。凌波不抵消攻击附带的虚弱等减益，除非宿主原本就规定该减益必须实际造成生命伤害才能施加。

凌波不会在你点击结束回合时消失，因此可以用于敌方行动。回合开始清除旧凌波后，新产生的凌波保留。例如易经心法在新回合给予的凌波不能被同一次清理删除。

## 4. 六种剑气

“剑气”是严格的卡牌身份集合：DY_T01少商、DY_T02商阳、DY_T03中冲、DY_T04关冲、DY_T05少冲、DY_T06少泽。升级与复制不改变身份。图鉴的“北冥／凌波／六脉／通用”标签只是构筑分类；被标记为六脉的生成技能不因此成为剑气。

### 获得、生成与升级

- 六剑全部是0费攻击，消耗、虚无；不进入普通奖励、商店卡牌、战斗外随机变牌或永久牌组。
- 没有写“升级版本”或“+”时，生成未升级剑气。生成器升级不自动升级产物，必须以升级后的完整文本为准。
- 从六种中选择时，六种始终可选，不要求解锁或已拥有。选择多个不同剑式时不能重复，按玩家选择顺序逐张加入。
- “六种各1张”按少商、商阳、中冲、关冲、少冲、少泽的固定顺序加入。
- 生成时手牌已满，新牌进入弃牌堆；抽牌时手牌已满，停止继续抽取，剩余牌留在抽牌堆。空抽牌堆时按宿主洗回弃牌堆的规则补充。
- 虚无只在回合末消耗仍位于手牌中的牌；满手溢出到弃牌堆的剑气不会被跨区域清理。由逆运经脉主动弃置剑气也能保存到下一轮抽取，属于允许的战术。
- 同时拥有保留和虚无的牌，虚无优先；乾坤步不能救下手中的剑气。临时“本回合保留”只跳过本次正常弃牌，不让牌永久保留。
- 剑气最多升级一次，重复升级不叠加。剑气归宗只升级当时实际在手中的剑气，不能升级因满手刚刚进入弃牌堆的少商剑气。

### 生成不等于打出

生成、抽到、复制卡牌对象、从消耗堆取回，都不触发“打出剑气”。六张剑气分别打出时是六次攻击事件；中冲对多个敌人伤害只算一次打出。

实际自动再次打出是一轮新的打牌事件，重新检查耗气、目标与计数；若外部效果免除能量费用，不因此免除真气。仅重复一个伤害效果，不制造新的打牌事件。复制卡牌对象继承其升级状态，能力触发不因复制动作本身发放。

## 5. 一次打牌的顺序

1. 检查能量、必要目标与合法性。将牌移出手牌并锁定其原目标；支付能量。手牌空位此时已经释放。
2. 登记本次实际打出：所属玩家的技能／攻击／剑气次数和剑式集合增加。记录该牌在各计数中的序号。
3. 按正文顺序执行效果。多段伤害分别结算力量等修正；出现耗气时立刻检查并支付，完成其附加效果，再处理相关耗气能力。
4. 处理该牌正文结算后的收益：先按取得顺序处理遗物，再按能力生效顺序处理能力。此时该牌仍在宿主的出牌区域；新安装的能力已经生效，但使用出牌前快照，不对自己这次打牌追溯触发。
5. 本次打牌的全部重复执行完成后，由宿主按关键词将牌移至消耗堆或弃牌堆，能力牌离开出牌区域。若存在Replay，每次重复执行各自登记次数、结算正文并触发卡后收益，最终只进行一次区域转移。

这个顺序对应目标游戏版本的`CardModel.OnPlayWrapper`：正文→`AfterCardPlayed`→最终移牌。因此卡后抽牌不能在同一次洗牌中抽回仍处于出牌区域的本牌；它也尚未成为可从弃牌堆或消耗堆选择的目标。原始设计稿中先移牌再触发卡后收益的顺序已据此修正，避免替换宿主整个打牌流程。

同一时点的多个效果使用稳定的取得／生效顺序，不依赖动画速度。联机由权威事件队列排序，客户端只能展示已确认的结果。

若打出时要求一个敌人或存活玩家，但目标在支付前已经无效，取消出牌且不支付。支付后目标死亡或失效时，该目标对应效果跳过，其他句子继续；不自动重选目标。玩家自身死亡时终止其尚未执行的本张牌效果及收益，因此舍身相护可能在生命不足时无法提供保护。整场战斗结束时终止所有余下动作，不继续抽牌、返气或触发奖励。

没有可选剑气时可以空放剑随心转：不生成、不抽牌，仍支付费用并消耗自身。没有合法目标卡时，生生不息、内息归元等“至多”效果允许选择0张。生生不息排除基础ID为DY_R19的所有版本与复制牌，显示名称带“+”也不能绕过。

## 6. 计数、叠加与能力

所有“每回合前N张／前N次／首次第3种”的判断使用从本人回合起点累计的记录，包含能力打出之前发生的行为。获得能力不重置记录、不补发过去收益。例如已经打过2张技能才打出凌波微步，本回合后续技能不会获得它的前2张奖励。

同名能力叠加数值，不叠加次数上限；不同名字的能力独立结算。例：两层北冥神功使本回合前2次成功耗气各返2真气，不是前4次各返1；两层指法纯熟使前2张剑气伤害各增加4，而不是前4张增加2。升级与未升级版本共用同一身份，各自的数值相加。

| 能力 | 计数或读取时点 |
| --- | --- |
| 北冥初成 / 北冥神功 | 当回合成功耗气的序号；附加效果完成后抽牌／返气。 |
| 凌波微步 | 该技能打出时登记的技能序号；该牌结算后获得凌波。 |
| 指法纯熟 / 无相之境 | 当前剑气的打出序号；前者影响本牌攻击，后者在本牌结算后给格挡。 |
| 六脉贯通 | 剑式集合第一次由2种变3种的那张牌；第四种及以后的牌不补发。 |
| 风过无痕 | 本回合第一次实际发生凌波减伤；格挡在该段生命结算之后获得。 |
| 真气护体 | 自身回合结束效果执行时的真气；先向下取整一半，再加升级固定值。 |
| 不争之心 | 本回合攻击打出数为0；剑气也算攻击，即使造成0伤害。 |
| 守拙 | 自身回合结束、未用能量清空之前检查；至少有1点就只运气一次，不按能量数倍增。 |
| 易经心法 / 无形剑阵 | 从打出后的下一次自身回合开始起生效，不立即补发。 |

凝气成锋与指法纯熟的固定伤害加成在力量所在的基础伤害加法阶段加入，再应用虚弱／易伤等修正。中冲对每个敌人的一段伤害都可获得该加成；不会因目标数量而额外增加出牌次数。凝气成锋多次打出的数值相加，在本回合结束时清除。

多次独立“获得格挡”各自应用宿主的敏捷／脆弱修正。援手、同行、舍身相护的格挡使用接收者的这些修正；施术者不把自己的敏捷转移给队友。凌波始终为固定减3。

## 7. 回合边界

本节只约定新增效果的顺序，不要求替换宿主全部回合系统。实现必须将新效果挂在能达到下述结果的宿主时点。

**自身回合开始：** 先快照上一回合记录供枯荣禅珠使用，再清除旧凌波并重置本回合计数。新的回合开始格挡必须在宿主清理旧格挡之后授予，不能立刻被删掉。随后按“已排队的下回合效果 → 遗物 → 能力”的顺序处理本设计的回合开始效果，同类按生成／取得顺序。此窗口在基础抽牌前执行；倒踩七星的额外抽牌与基础抽牌分别处理，均遵守手牌上限。

**自身回合结束：** 在能量清空前，先按能力的生效顺序处理守拙、真气护体、不争之心等回合结束能力；再按宿主规则处理手牌中的虚无、保留与正常弃牌，清除仅限本回合的剑气伤害加成。凌波和真气继续保留至其各自规定的清理点。

能力顺序是有意义的：先获得守拙、后获得真气护体时，守拙增加的真气可以在同一次回合结束被护体读取；顺序相反时不能追溯增加格挡。界面应按实际顺序显示能力，战斗日志展示每次读取的真气。

延迟效果逐个保存，不覆盖：两张以退为进会在下回合各运气2；多次倒踩七星各额外抽1。战斗结束移除未触发的延迟效果，不带入下一战。

## 8. 多人模式

真气、技能数、剑气身份集合和触发次数全按所属玩家隔离。多名段誉各自管理自己的资源；队友打牌不能帮你凑六脉贯通，也不能用你的气。

共享玩家阶段中，每名角色只在其阶段起点重置一次计数。一个玩家结束行动、队友继续行动，不开启新的个人回合。支援牌可以选择仍存活且已经结束行动的队友；其抽到的牌不会自动重新开放行动，是否还能出牌遵循宿主规则。凌波仍持续至该接收者的下一回合开始。

同时出牌按权威队列锁定目标与资源：若确认时目标合法，随后队友击杀该敌人，按目标失效规则跳过对应效果。由本牌伤害导致的击杀才能触发留三分力；队友击杀或随后毒伤击杀不算。

本版有3张明确支援牌：援手、同行、舍身相护。其余默认作用于自己或敌人。专属事件的资源与奖励归属见[遗物与事件](relics-and-events.md)。

## 9. 验收例

下表是必须实现的预期行为，尚不表示已通过实际游戏验收。

| 情形 | 预期 |
| --- | --- |
| 真气8，运气3。 | 真气9，丢失2点溢出。 |
| 真气1，首张技能为抱元守一，持有玉佩。 | 先获得7格挡，耗气失败；牌结算后运气1，最终真气2。 |
| 真气2，北冥初窥→凌波初步→无意一指。 | 花3能量，9格挡、凌波1、12伤害、剩余真气3；假定敌人存活且无其他修正。 |
| 格挡4、凌波3，承受5点伤害5次。 | 段值为2、2、2、5、5；总计16，格挡吸收4，失去12生命。 |
| 格挡20、凌波1，承受5点攻击。 | 凌波归0，格挡剩18，生命不变。 |
| 凌波1，承受原本0点攻击。 | 保留凌波1；不触发风过无痕。 |
| 凌波1、风过无痕、格挡0，承受5点攻击。 | 先失去2生命，再获得4格挡；不能用新格挡吸收刚才那2点。 |
| 六脉神剑耗气效果执行时手中8张，上限10。 | 少商、商阳入手，其他4张进入弃牌堆；生成不算打出。 |
| 手中剑气获得本回合保留。 | 回合结束仍因虚无消耗。 |
| 少商→少商+→商阳→关冲，六脉贯通已生效。 | 在关冲结算后首次达到3种并触发；升级少商不是新剑式。 |
| 耗气将真气从3变0，同时拥有北冥神功和大理国印。 | 国印记录已触发条件；神功返气后，国印仍在本牌结算后给能量。 |
| 扣脉在真气0时打出。 | 造成基础伤害，不抽牌，仍消耗。 |
| 2点生命打出舍身相护。 | 自伤致死，后续给格挡和凌波不执行；与事件禁用致死选项是不同规则。 |
