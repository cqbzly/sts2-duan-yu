# 大理世子·段誉｜《杀戮尖塔2》角色模组

**不愿争胜，却身负绝学；以游身积气，以无形剑气破局。**

以金庸《天龙八部》的段誉为原型，设计一名通过技能蓄积真气、以凌波争取时间、用六脉剑气主动破局的角色。绝学“时灵时不灵”体现为清晰的资源门槛：气足则发，气不足仍执行基础效果，不使用随机哑火。

当前版本为 **v0.1.1 开发预览版**。仓库包含角色程序、75张常规卡、5种基础牌、6种衍生剑气及全部升级、8件专属遗物、2个事件、中文文本与本地生成的角色资源。目标环境为《杀戮尖塔2》v0.113.1 public-beta 与 BaseLib 3.4.8；验证范围及尚未完成的兼容性测试见[实现与测试记录](docs/implementation-and-testing.md)。

## 安装与开发

玩家安装步骤见[安装说明](docs/installation.md)。模组只依赖 BaseLib，安装包包含 `CQBZLY_DUAN_YU.dll` 和对应JSON清单；图像与场景在本地生成并缓存，不需要额外下载资源或PCK。

开发需要 .NET 9 SDK，以及合法安装的目标版本游戏。仓库不包含游戏程序集。

```powershell
.\scripts\build.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
.\scripts\package.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
```

源码位于 `src/DuanYu/`。构建默认不安装到游戏；安装脚本会备份同名旧模组文件。

## 三个机制

**北冥真气。** “运气N”增加真气，超过9点的部分丢失。“耗气N：……”在执行到这一句时检查资源：足够就自动扣除并执行附加效果，不足就跳过。不能预支技能结算后由玉佩提供的真气，也不能选择拒绝支付。是否出牌、先出哪张牌，就是管理内力的关键。

**凌波卸力。** 将要承受一段正数攻击伤害时，先消耗1层凌波，使修正后的伤害降低3点，然后结算格挡。多段攻击逐段处理；旧凌波在自己的下回合开始时清除。它尤其善于应对连续小攻击，对一次重击只能减3点。

**六脉变招。** 六种剑气各有分工，可通过通用生成器自由选择，不要求集齐六张指定卡。它们都是独立攻击牌，不能仅靠生成就触发打牌收益。基础六剑如下，升级文本见图鉴。

| 剑气 | 基础效果 |
| --- | --- |
| 少商剑气 | 7点伤害。 |
| 商阳剑气 | 4点伤害，给予目标1层易伤。 |
| 中冲剑气 | 对所有敌人造成5点伤害。 |
| 关冲剑气 | 4点伤害，获得4点格挡。 |
| 少冲剑气 | 3点伤害，抽1张牌。 |
| 少泽剑气 | 3点伤害，给予目标1层虚弱。 |

六剑均为0费、消耗、虚无。名称里的“剑气”与构筑标签不能混淆：规则中的剑气严格指这6种衍生牌。

## 卡池与构筑

常规奖励卡池由20张普通、35张罕见、20张稀有组成；这是本项目选定的设计规模，不是对官方角色卡池数量的断言。基础牌和衍生牌不进入常规奖励、商店卡牌或随机变牌候选池。

- **北冥蓄势：** 吐纳、气海充盈积气，蓄势一击保留储备，以气催劲、天南一指兑现；不能一味等满气。
- **凌波游身：** 掠影步、倒踩七星、风过无痕稳定防守，回身一指与真气攻击结束战斗；多段减伤无法替代对重击的格挡。
- **六脉变招：** 记诵剑谱、双脉并进、无形剑阵生成剑气，指法纯熟、六脉贯通奖励出牌；先施加易伤，再安排伤害与抽牌。

## 数据维护与校验

无需安装依赖，使用 Node.js 18 或更新版本。本次在 Node.js 24.16.0 下验证。

```sh
node scripts/build-cards.mjs
node scripts/validate.mjs
```

`data/cards.json` 是卡牌文本的唯一数据源。第一条命令生成图鉴；第二条检查86种卡牌、稀有度分布、ID和名称唯一性、10张初始牌组、基础与升级文本、衍生引用以及生成文档一致性。人物、遗物、事件、规则和平衡文档由人工维护。

通过数据校验不等于通过实战平衡、联机同步或模组兼容性测试。设计审查已经修复“记诵剑谱+零费生成少冲剑气并抽回自身”的直接无限循环；当前实现已通过13项规则测试、115项资源测试和186组游戏引擎自测，与其他角色、遗物及免费出牌效果的全部组合仍需进一步验证。

## 作品来源与实现边界

人物与武学主题源于金庸《天龙八部》；卡牌文本、数值、遗物效果、事件叙事与视听方案为本项目的同人改编。《杀戮尖塔2》由 Mega Crit 开发，本项目与其官方没有隶属关系。

产品范围参考2026-11-17核对的[官方 Steam 页面](https://store.steampowered.com/app/2868840/Slay_the_Spire_2/)，包含单人与在线合作。此仓库包含设计规格、C#实现及结构化资料，不分发游戏二进制、游戏原版美术或影视截图。当前插画是项目内程序化绘制的简化图形，部分通用音效与能量界面由已安装游戏提供。
