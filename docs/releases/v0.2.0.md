# v0.2.0 本地候选版

v0.2.0 是段誉模组的本地候选版本，尚未替换 GitHub 上已发布的 v0.1.1 安装包，也不代表已经完成完整 A10 通关。候选版本面向本地代码审阅、单元测试和游戏内回归；Steam 创意工坊条目仍保持私有测试状态。

## 内容变化

- **卡牌平衡：** 调整35张卡牌的费用、伤害、格挡、运气、耗气、回能和生成文本；`data/cards.json` 是唯一数据源，图鉴已重新生成。
- **六脉剑气：** 六种衍生牌仍为0费、消耗、虚无；少商、中冲、关冲、少泽增加明确耗气分支，商阳和少冲提供有限运气，所有生成关系与升级文本同步。
- **资源出口：** 读书明理、气海充盈、涌泉引气、百川归海、少泽剑气等效果按牌面提供有限能量；北冥神功、六脉贯通、守拙的回能受每回合门槛限制。
- **兼容性：** 增加 Architect 专属结尾对话，提供中英文各3句、支持宿主要求的第0/1/100次访问，避免胜利房缺少专属对话时的空引用；后续仍交由原生 final option 进入 `RunManager.WinRun`。
- **凌波修复：** 修正凌波错误减免 `Unpowered` 非攻击伤害的问题。Wither、Burn、Toxic 等非攻击状态伤害可按宿主规则被格挡，但不触发凌波。
- **宣传资源：** 使用现有 `artifacts/card-art` 重新生成 `assets/card-gallery.png` 和 `assets/workshop-preview.png`，不在游戏内卡面插画中嵌入费用或规则文本。
