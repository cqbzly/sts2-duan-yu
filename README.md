# 大理世子·段誉｜《杀戮尖塔2》角色模组

**不愿争胜，却身负绝学；以游身积气，以无形剑气破局。**

以金庸《天龙八部》的段誉为原型，设计一名通过技能蓄积真气、以凌波争取时间、用六脉剑气主动破局的角色。绝学“时灵时不灵”体现为清晰的资源门槛：气足则发，气不足仍执行基础效果，不使用随机哑火。

当前版本为 **v0.3.0 开发预览版**，已安装到本机现有工坊目录。仓库包含75张常规卡、5种基础牌、6种衍生剑气、2种不可升级的状态牌、8件专属遗物、2个事件与角色程序。v0.3.0将常规攻击由18张增至32张，大幅提高输出；书生意气与大梦初醒固定提供资源，随机性集中在剑招与跨角色借招；主动消耗可以把状态牌和剩余手牌炼成格挡、真气及新剑。目标环境为《杀戮尖塔2》v0.113.1 public-beta 与 BaseLib 3.4.8；完整 A10 已通关并在新进程复现，状态见[实现与测试记录](docs/implementation-and-testing.md)。

v0.3.0本轮已通过规则23/23、最终游戏引擎283/283、资源118/118和88张卡牌数据校验；88张卡面已导出，Debug与Release均0警告、0错误。完整A10种子 `DUANYUFULLA10-048` 两次从头运行均击败Kin、Insatiable、Queen与Aeonglass，最后一战后72/72生命并完成原生结局。这是headless原生流程自动策略与同种子复现，不是玩家胜率；证据、日志告警和范围见[完整 A10 验证](docs/full-run-validation.md)。

## 安装与开发

玩家安装步骤见[安装说明](docs/installation.md)。模组只依赖 BaseLib，安装包包含 `CQBZLY_DUAN_YU.dll` 和对应JSON清单；图像与场景在本地生成并缓存，不需要额外下载资源或PCK。

开发需要 .NET 9 SDK，以及合法安装的目标版本游戏。仓库不包含游戏程序集。

```powershell
.\scripts\build.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
.\scripts\package.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
```

源码位于 `src/DuanYu/`。构建默认不安装到游戏；安装脚本会备份同名旧模组文件。

## 核心机制

**北冥真气。** “运气N”增加真气，超过9点的部分丢失。“耗气N：……”在执行到这一句时检查资源：足够就自动扣除并执行附加效果，不足就跳过。不能预支技能结算后由玉佩提供的真气，也不能选择拒绝支付。是否出牌、先出哪张牌，就是管理内力的关键。

**凌波卸力。** 将要承受一段正数攻击伤害时，先消耗1层凌波，使修正后的伤害降低3点，然后结算格挡。多段攻击逐段处理；旧凌波在自己的下回合开始时清除。它尤其善于应对连续小攻击，对一次重击只能减3点。

**六脉变招。** 六种剑气各有分工，可通过通用生成器自由选择，不要求集齐六张指定卡。它们都是独立攻击牌，不能仅靠生成就触发打牌收益。基础六剑如下，升级文本见图鉴。

**剑势成长。** 每张剑气实际结算后获得1层剑势；每回合首次打出第3种不同剑气额外获得1层，第6种额外获得2层。六种各打一次可从0升至9层，最高12层；当前剑完成伤害后才增加剑势。每层为之后的剑气每段伤害加1，普通攻击不受影响。

**主动炼化。** 生生不息先获得8/12格挡，再消耗全部其他手牌，按实际数量生成随机剑气，允许重复；本牌不自耗，可以下一轮再用。逆运经脉单张消耗后固定抽牌，内息归元多张消耗换气与格挡，百脉归炉每次消耗补格挡；不染尘可集中清除手中状态牌。先打出想保留价值的核心，再清理状态与剩余废牌。

| 剑气 | 基础效果 |
| --- | --- |
| 少商剑气 | 12点伤害。耗气1：再造成6点伤害。 |
| 商阳剑气 | 8点伤害，给予目标1层易伤。运气2。 |
| 中冲剑气 | 对所有敌人造成8点伤害。耗气2：再对所有敌人造成6点伤害。 |
| 关冲剑气 | 8点伤害，获得8点格挡。耗气1：再获得8点格挡。 |
| 少冲剑气 | 5点伤害，抽1张牌。运气2。 |
| 少泽剑气 | 7点伤害，给予目标1层虚弱。耗气1：获得1点能量。 |

六剑均为0费、消耗、虚无。名称里的“剑气”与构筑标签不能混淆：规则中的剑气严格指这6种衍生牌。

## 卡池与构筑

常规奖励卡池由20张普通、35张罕见、20张稀有组成，其中攻击32张；这是本项目选定的设计规模，不是对官方角色卡池数量的断言。基础牌、六剑和两种状态牌不进入常规奖励、商店卡牌或随机变牌候选池。14张原技能现在是攻击，即使同时给格挡或生成剑，也不再触发玉佩首技能及凌波微步。

- **北冥蓄势：** 吐纳、气海充盈积气，蓄势一击保留储备，以气催劲、天南一指兑现；不能一味等满气。
- **凌波游身：** 掠影步、倒踩七星、风过无痕稳定防守，回身一指与真气攻击结束战斗；多段减伤无法替代对重击的格挡。
- **六脉变招：** 记诵剑谱、双脉并进、无形剑阵生成剑气，指法纯熟、六脉贯通奖励出牌；先施加易伤，再安排伤害与抽牌。
- **北冥炼化与借招：** 逆运经脉、内息归元、生生不息清理手牌；百脉归炉奖励消耗，北冥借招提供外门攻击与后续异种真气，不要求集齐金卡才能开始运作。

书生意气固定抽2/3张，至少5气再抽1，然后固定获得2/3气、1能量、2/3剑势；大梦初醒先清空格挡并抽3/4张，再固定获得4/6气、2能量、4/6剑势。随机只决定剑随心转、北冥借招和生生不息生成的招式身份。气滞不可打出、虚无，留到手牌回合末扣2气；异种真气为1费状态，运气3、剑势2、抽1、消耗。两种状态均不可升级。

## 数据维护与校验

无需安装依赖，使用 Node.js 18 或更新版本。

```sh
node scripts/build-cards.mjs
node scripts/validate.mjs
```

`data/cards.json` 是卡牌文本的唯一数据源。第一条命令生成图鉴；第二条检查88种卡牌、稀有度分布、ID和名称唯一性、10张初始牌组、基础与升级文本、状态牌不可升级、剑气/状态生成引用以及生成文档一致性。人物、遗物、事件、规则和平衡文档由人工维护。

通过数据校验不等于通过实战平衡、联机同步或模组兼容性测试。当前卡池的回能、抽牌与回收组合仍需持续检查；规则、资源与引擎测试覆盖见[实现与测试记录](docs/implementation-and-testing.md)，完整 A10 流程结果见[完整流程验证](docs/full-run-validation.md)。
