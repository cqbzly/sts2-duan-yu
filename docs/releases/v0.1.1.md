# v0.1.1 开发预览版

本版提供完整可玩的段誉角色程序，并为86种卡牌接入新的原创矢量卡面。初版GitHub仓库仅有角色设计，本次发布同时补齐程序、测试、安装脚本与构建说明。

- 角色内容：86种卡牌及升级、8件遗物、2个事件；北冥真气、凌波卸力、六脉剑气完整结算。
- 卡面：18类语义场景，1000×760分辨率，六剑各自有不同轨迹；附卡面精选和工坊封面。
- 工具：可重复构建、规则测试、资源导出、安装包与私有工坊工作区生成。
- 验证环境：Windows，游戏v0.113.1 public-beta，BaseLib 3.4.8与Compatibility Helper。

本次验证：规则测试13项通过；数据与图鉴一致性通过；资源加载115项通过；86张独立卡图均通过尺寸与导出检查；Debug/Release构建均为0警告、0错误；真实游戏引擎回归186组通过、0失败，退出码0。

Steam官方上传器已返回成功，条目ID为[3841781260](https://steamcommunity.com/sharedfiles/filedetails/?id=3841781260)，上传可见性为private，BaseLib依赖3737335127已添加。私有条目需要发布账号登录查看，匿名API无法读取详情；本次没有订阅回装验证。GitHub版本地址为[v0.1.1](https://github.com/cqbzly/sts2-duan-yu/releases/tag/v0.1.1)。

完整通关平衡、远程多人、图形界面重开后继续存档和第三方模组组合尚未验证。引擎测试退出时有Godot资源回收提示，未完成泄漏归因。详见[测试记录](../implementation-and-testing.md)和[兼容性检查](../compatibility-and-publishing.md)。
