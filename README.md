# 大理世子·段誉｜《杀戮尖塔2》角色模组

**不愿争胜，却身负绝学；以游身积气，以无形剑气破局。**

以金庸《天龙八部》的段誉为原型，设计一名通过技能蓄积真气、以凌波争取时间、用六脉剑气主动破局的角色。绝学“时灵时不灵”体现为清晰的资源门槛：气足则发，气不足仍执行基础效果，不使用随机哑火。

当前版本为 **v0.4.0 本地再平衡候选**。本轮将凌波、剑势、六剑资源门槛和随机生成重新收紧，目标是让 A10 自动采样接近可玩的中等胜率；本轮代码和引擎结果仍以本地测试报告为准，未宣称新的完整通关或玩家胜率。目标环境为《杀戮尖塔2》v0.113.1 public-beta 与 BaseLib 3.4.8；历史发布版本见[实现与测试记录](docs/implementation-and-testing.md)。

v0.3.0 的规则、引擎和单种子 A10 结果属于上一版基线；凌波减伤3、剑势跨回合和剑气附加资源已不再代表当前版本。v0.4.0 需要重新运行规则、引擎、资源和 A10 多种子测试，报告会区分胜利、失败与异常，不把单种子成功当作胜率。

![段誉卡面精选](assets/card-gallery.png)

卡面程序覆盖全部88种卡牌，包含气滞的闭塞经脉、异种真气的双色流转与百脉归炉的炼化场景。宣传图为画册排版示意，游戏中沿用原生卡框和文本。详见[卡面设计与导出](docs/card-art.md)。

历史版本下载：[GitHub v0.3.0](https://github.com/cqbzly/sts2-duan-yu/releases/tag/v0.3.0)。[Steam创意工坊条目](https://steamcommunity.com/sharedfiles/filedetails/?id=3841781260)仍是上一版 private 条目；v0.4.0 完成本地验证后再决定是否上传。

**历史验证：** v0.2.1 的种子 `DUANYUFULLA10-001` 从初始牌组完成三幕、四首领及原生结局，最后一战剩77/83生命，新进程同种子复现成功。当时采用 headless 原生流程自动策略，未追加属性或指定奖励；首个种子胜利后停止搜索。旧版规则23项、引擎235项、资源116项及86种卡牌数据校验通过，不能作为 v0.3.0 新机制的通过结论，也不代表玩家胜率。新版操作与历史实录见[A10 小抄](docs/cheat-sheet.md)，证据见[完整 A10 验证](docs/full-run-validation.md)。

## 安装与开发

玩家安装步骤见[安装说明](docs/installation.md)。模组只依赖 BaseLib，安装包包含 `CQBZLY_DUAN_YU.dll` 和对应JSON清单；图像与场景在本地生成并缓存，不需要额外下载资源或PCK。

开发需要 .NET 9 SDK，以及合法安装的目标版本游戏。仓库不包含游戏程序集。

```powershell
.\scripts\build.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
.\scripts\package.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
```

源码位于 `src/DuanYu/`。构建默认不安装到游戏；安装脚本会备份同名旧模组文件。

## 核心机制

**北冥真气。** “运气N”增加真气，超过9点的部分丢失。六种剑气是关键的真气支出：没有至少1点真气时不能发动，发动时立即支付1点。其他卡牌的“耗气N”仍在结算到该句时检查资源，不足时跳过附加效果。不能预支本牌后续才获得的真气，也不能选择拒绝支付。

**凌波卸力。** 将要承受一段正数攻击伤害时，先消耗1层凌波，使修正后的伤害降低1点，然后结算格挡。多段攻击逐段处理；旧凌波在自己的下回合开始时清除。它是小幅缓冲，不能替代格挡。

**六脉变招。** 六种剑气各有分工，通用生成器使用战斗随机数无放回抽取，减少手动选牌和确定性循环。它们都是独立攻击牌，必须支付1点真气才能发动，不能仅靠生成就触发打牌收益。基础六剑如下，升级文本见图鉴。

**剑势成长。** 每张剑气实际结算后获得1层剑势；每回合首次打出第3种不同剑气额外获得1层，第6种额外获得1层。六种各打一次可从0升至8层，最高8层；每回合开始剑势清零，当前剑完成伤害后才增加剑势。每层为之后的剑气每段伤害加1，普通攻击不受影响。

**主动炼化。** 生生不息先获得8/12格挡，再消耗全部其他手牌，按实际数量生成随机剑气，允许重复；本牌不自耗，可以下一轮再用。逆运经脉单张消耗后固定抽牌，内息归元多张消耗换气与格挡，百脉归炉每次消耗补格挡；不染尘可集中清除手中状态牌。先打出想保留价值的核心，再清理状态与剩余废牌。

| 剑气 | 基础效果 |
| --- | --- |
| 少商剑气 | 需1点真气；造成10点伤害，再造成4点伤害。 |
| 商阳剑气 | 需1点真气；造成6点伤害，给予目标1层易伤。 |
| 中冲剑气 | 需1点真气；对所有敌人造成6点伤害，再造成4点伤害。 |
| 关冲剑气 | 需1点真气；造成6点伤害，获得6点格挡。 |
| 少冲剑气 | 需1点真气；造成4点伤害，抽1张牌。 |
| 少泽剑气 | 需1点真气；造成5点伤害，给予目标1层虚弱。 |

六剑均为0费、消耗、虚无，且每次发动支付1点真气。名称里的“剑气”与构筑标签不能混淆：规则中的剑气严格指这6种衍生牌。

## 卡池与构筑

常规奖励卡池由20张普通、35张罕见、20张稀有组成，其中攻击32张；这是本项目选定的设计规模，不是对官方角色卡池数量的断言。基础牌、六剑和两种状态牌不进入常规奖励、商店卡牌或随机变牌候选池。14张原技能现在是攻击，即使同时给格挡或生成剑，也不再触发玉佩首技能及凌波微步。

- **北冥蓄势：** 吐纳、气海充盈积气，蓄势一击保留储备，以气催劲、天南一指兑现；不能一味等满气。
- **凌波游身：** 掠影步、倒踩七星、风过无痕稳定防守，回身一指与真气攻击结束战斗；多段减伤无法替代对重击的格挡。
- **六脉变招：** 记诵剑谱、双脉并进、无形剑阵生成剑气，指法纯熟、六脉贯通奖励出牌；先施加易伤，再安排伤害与抽牌。
- **北冥炼化与借招：** 逆运经脉、内息归元、生生不息清理手牌；百脉归炉奖励消耗，北冥借招提供外门攻击与后续异种真气，不要求集齐金卡才能开始运作。

书生意气为2费，固定抽2/3张，至少5气再抽1，然后运气2/3并获得1/2层剑势，不提供能量；大梦初醒为1费，先清空格挡并抽3/4张，再运气3/4、获得1点能量和2/3层剑势。随机只决定剑随心转、北冥借招和生生不息生成的招式身份。气滞不可打出、虚无，留到手牌回合末扣2气；异种真气为1费状态，运气3、剑势2、抽1、消耗。两种状态均不可升级。

## 数据维护与校验

无需安装依赖，使用 Node.js 18 或更新版本。

```sh
node scripts/build-cards.mjs
node scripts/validate.mjs
```

`data/cards.json` 是卡牌文本的唯一数据源。第一条命令生成图鉴；第二条检查88种卡牌、稀有度分布、ID和名称唯一性、10张初始牌组、基础与升级文本、状态牌不可升级、剑气/状态生成引用以及生成文档一致性。人物、遗物、事件、规则和平衡文档由人工维护。

通过数据校验不等于通过实战平衡、联机同步或模组兼容性测试。当前卡池的回能、抽牌与回收组合仍需持续检查；规则、资源与引擎测试覆盖见[实现与测试记录](docs/implementation-and-testing.md)，完整 A10 流程结果见[完整流程验证](docs/full-run-validation.md)。
