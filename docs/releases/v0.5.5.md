# v0.5.5：合并卡牌效果

逐张审核96种卡牌的基础与升级说明，将旧代码里同一目标的固定重复伤害合为一次结算，牌面直接显示合计数值。力量、剑势和附魔只应用一次；实际伤害执行与牌面同步。

| 卡牌 | 基础 / 升级效果 |
| --- | --- |
| 少商剑气 | 一次7/10伤害。 |
| 中冲剑气 | 对所有敌人各造成一次5/7伤害。 |
| 无意一指、借力 | 一次20/28伤害。 |
| 以气催劲 | 一次30/42伤害。 |
| 气贯长虹 | 对所有敌人各造成一次23/31伤害。 |
| 一气贯之 | 一次33/45伤害。 |
| 天南一指 | 一次58/79伤害。 |
| 内力震荡 | 对目标造成54/72伤害，对其他敌人造成22/29伤害，各只命中一次。 |
| 六脉齐发 | 对所有敌人各造成一次7/10×(X+1)基础伤害。 |
| 万流归宗 | 一次获得4/6×X基础格挡。 |

其余说明去除冗句，保留目标、必要条件与结算时点。按实际消耗张数触发的收益、不同回合的收益与独立原生Replay继续按各自规则触发。完整基础与升级文本见[卡牌图鉴](../cards.md)，实战资源账见[小抄](../cheat-sheet.md)。

其他平衡规则沿用v0.5.4。百川归海基础/升级均1费，运气2/3、回能1/2、抽2、消耗。初始牌组仍为4打击、4防御、北冥初窥、无意一指，共10张。玉佩开场3气，自己的回合末全部效果结算后失去1气；真气费用仍在整张牌执行前强制支付。
