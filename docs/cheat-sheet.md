# 段誉 · A10 实战小抄

本文对应 v0.5.35。初始牌组有 4 张打击、4 张防御、北冥初窥与无意一指。真气无上限，跨回合保留，打牌前须付足真气。每张剑气通常需 1 点真气，经脉归一生成的剑气免费。六脉齐发用尽真气，每花 1 点就对同一目标造成一段 6/8 点伤害，各段独立应用增伤。每层凌波使每段可格挡伤害减 1，层数到自己的下回合开始时清除。风过无痕每新增 1 层凌波提供 3/5 格挡。剑势上限为 8，每回合开始清零。头环开战运气 5，自己的每个回合结束时运气 1。[卡牌图鉴](cards.md) · [v0.5.35 更新记录](releases/v0.5.35.md)

奥罗巴斯的升级初始遗物选项现在将玉佩换成段誉专属头环，不会换成原版无效果头环。升级后每场战斗开局5气，每个自己的回合结束补1气，超过9气仍正常获得。

## 开打前检查

| 检查 | 立即执行的判断 |
| --- | --- |
| 初始攻防 | 4打击、4防御各按原生基础数值6伤害、5格挡计算。早期防守依靠防御和北冥初窥，初始牌组没有凌波减伤；无意一指先支付2气，再造成一次16/22伤害。 |
| 首张技能 | 玉佩不再按首张技能返还资源；先按牌面支付和结算。攻击、能力与状态也不会触发玉佩额外奖励。 |
| 关键费用 | 六脉神剑只花2能量。每张生成的剑气另需1气才能打出。 |
| 出剑顺序 | 先铺增伤、易伤，再打主力剑；需要续打时给少泽留气，不要先被其他剑自动花光。 |
| 剑式计数 | 玉佩不再奖励第3/第6种剑；六脉贯通、六脉图谱等牌或遗物仍按各自文本计数。升级版仍算同一种，生成器随机发剑。 |
| 剑势 | 每张剑结算后加1层；每回合第3种额外加1、第6种额外加1；上限8，回合开始清零。当前剑打完才涨，下一张剑吃到新层数。 |
| 手牌空间 | 六脉神剑打出前最好不超过5张手牌，六剑才能全部入手；满手溢出的剑进弃牌堆，本轮不一定抽得回来。 |
| 回合结束 | 真气保留，不自然流失；手中的气滞仍失去2气再虚无消耗。凌波保留至自己的下回合开始；可格挡状态伤害会减免，明确失去生命的效果不受影响。 |
| 主动消耗 | 先用有价值的核心，再用逆运经脉、内息归元、生生不息或不染尘清状态；自身“消耗”不等于能清掉其他手牌。 |

## 六剑速查

六种都是0费攻击，消耗、虚无；经脉归一生成的剑气免费，其他来源的剑气需1点真气。表内“基础/升级”分别表示未升级与升级值。剑势每层为剑气加1伤害，之后再应用易伤、虚弱等修正；力量和其他剑气增伤也会改变实际伤害。

| 剑气 | 基础 / 升级伤害 | 耗气与附效 | 先想到的用途 |
| --- | --- | --- | --- |
| 少商 | 7 / 10，单体 | 一次伤害，剑势加成一次。 | 主力单体输出；先吃到易伤与增伤。 |
| 商阳 | 3 / 5，单体 | 伤害后给予1层易伤，升级不增加层数。 | 先手破防；不能靠本张回气。 |
| 中冲 | 5 / 7，全体 | 每个敌人各受一次伤害。 | 群怪仍在场时兑现群伤。 |
| 关冲 | 3 / 5，单体 | 获得3 / 5格挡。 | 即时防守，真气支出固定。 |
| 少冲 | 2 / 3，单体 | 抽1张。 | 续手；先腾手牌空间。 |
| 少泽 | 2 / 4，单体 | 伤害后给予1层虚弱，升级不增加层数。 | 降低来伤；别把最后1气花掉。 |

**要爆发先商阳，要减伤给少泽留1气，要防守优先关冲。** 凝气成锋为本回合的六种剑气和六脉齐发的每段伤害加2/3点。指法纯熟也为每段伤害加2/3点，无次数限制。已有第3/第6种奖励时，再把即将到达的门槛收入资源账。

## 剑势：先铺路，再兑现伤害

剑势上限8，每回合开始清零、战后清空。每层使六种剑气和六脉齐发的每段伤害加1。安全时让少商接在铺易伤和抽牌的剑后面，中冲用于清理群敌。

从0层开始连续打出六种不同剑气，打完后的层数为 **1→2→4→5→6→8**；第六剑使用打出前的6层，不能提前按8层计算。Replay 每次真实再次打出并结算都加1层，但同一种剑仍只算一种。满8层后继续打剑不再增加层数；无需为了成长放弃眼前斩杀或承受不必要伤害。

剑势奖励与玉佩分开算：第三种和第六种剑只带来剑势额外+1；六脉贯通或六脉图谱若在场，再按它们自己的文本结算。书生意气、大梦初醒与异种真气直接加剑势，不增加剑式数量；回合结束后剑势不保留。

| 状态挤满手、沙漏拖不动 | 逆运经脉单张清理，内息归元多张换格挡，生生不息整手换剑，不染尘只清状态。 | 为了凑循环把刚抽到的保命牌一并消耗，或只靠凌波硬扛状态伤害。 |

**金卡选择也看缺口。** 六脉神剑能提供整套攻防，百川归海同时补气、能量和手牌，北冥神功适合每回合能成功支付至少两次真气的牌组。拿到一张核心后，优先补它所缺的抽牌、伤害或防守，而不是继续堆同类启动牌。

**薄牌组的目标是准时抽到好牌。** 有足够输出前不要为删牌牺牲全部战力；有替代牌后再删基础牌。每次奖励只问一句：这张牌能解决下一段路线的哪一个问题？答不出就跳过。已有群伤仍要保留单体斩杀；已有凌波仍要保留实际格挡。

## 北冥炼化：先打核心，再清手

| 卡牌 | 主动消耗方式 | 用途 |
| --- | --- | --- |
| 逆运经脉 | 1费，选耗1张其他手牌，抽2/3张。若消耗了状态牌，多抽1张并运气1。 | 气滞或异种真气都能触发额外抽牌和运气。 |
| 内息归元 | 1费、自耗，选耗至多3/4张；每实际消耗1张运气1、格挡2/3。 | 多张废牌换眼前防守；选择0张也合法，但不凭空给按张收益。 |
| 百脉归炉 | 2费能力，每消耗1张获得2/3格挡；消耗两种专属状态时各额外运气1。 | 主动清理、剑气自耗和虚无都会形成防守；状态还能补回部分真气。 |
| 不染尘 | 2费、升级1费。清除脆弱、虚弱和易伤，获得7格挡，消耗手中所有状态牌，每张运气1并抽1张牌。 | 保留普通好牌，集中清状态；异种真气也是状态，会一起被清掉。 |

**对付沙漏与 Wither：** 先核对原生状态的回合末结算，再打出当前值得保留的能力、供气和防守。手里剩下状态与低价值牌时，用生生不息一次换成剑；只有一张状态就用逆运经脉，需要眼前格挡就用内息归元。把状态提前消耗，才能免掉它之后的手牌结算；明确失去生命的效果仍不能靠凌波减免。

**两种专属状态都能炼化。** 气滞由读书明理、逆脉强攻、斜行避势与借隙回身加入手牌。气滞不可打出、虚无，留在手牌到回合末才先扣2气再消耗。异种真气由蓄势一击、借招回锋与经脉归一加入手牌，或由北冥借招加入弃牌堆。抽到后花1能量换2气、1剑势、抽1并消耗。两种状态均不可升级。玉佩只在战斗开始提供3气。

两张借招牌都从其他角色的非基础攻击中抽取候选，包含角色专属事件牌和模组注入牌。它们保留借来牌的原有关键词，本回合固定能量费归零。X费、星星等其他资源费用和原生打出条件照常。借招回锋把异种真气放入手牌，北冥借招把它放入弃牌堆。[机制说明](mechanics.md)

## 出牌顺序：把回能真正接起来

### 玉佩只提供开场真气

玉佩只在战斗开始给3气。之后技能必须独立支付能量和耗气，不能把玉佩当作回能或额外抽牌来源；0费技能仍按自身牌面结算。

手里只有2气时，可以打出六脉神剑；若本回合不再运气，最多再发动其中两张剑气。

### 攻击生成器仍按攻击牌计算

当前的关冲护体是1费攻击：8/12伤害、4/6格挡，再生成未升级关冲。生成的关冲需要额外1点真气才能发动；剑气本身不再返气或回能。附带格挡或剑气不会改变生成器的攻击类型，计算时先确认当前真气和手牌空间。

少商起势、商阳点穴、中冲破阵、少冲探路、少泽回环也要重新看攻击类型。六脉神剑、记诵剑谱与剑随心转仍是技能；它们生成的剑气仍需按当前真气和随机剑式重新计算。双脉并进也是技能，但从消耗堆取回已升级的剑气，应先看消耗堆中有哪些升级剑式。

### 先装北冥，再花真气

北冥神功费用1、升级后0，每回合第2次成功支付真气后运气1并获得1能量。守拙回合开始供2气，在首张剑气结算后回能。六脉贯通在打出第3种和第6种不同剑气后结算。

耗气先支付，附加效果完成后才返还。不能拿未来返气支付眼前的门槛；多张北冥神功只叠加第2次支付的收益，不增加触发次数。六脉齐发一次付尽真气也只算一次支付，必须事先安排好出牌顺序。

### 资源账例：六剑需要逐张支付真气

假设开局3能量、3气，先花1能量打北冥初窥，获得5格挡和1气，此时剩2能量、4气；再用六脉神剑支付2能量，仍有4气，可以发动四张剑气；未花的真气跨回合保留。玉佩不会因技能追加资源，剑气不会返气或回能。该例假设已获得六脉神剑，它不属于初始牌组。

六脉神剑结算后，优先打关冲维持格挡或打少泽施加虚弱，取决于敌人意图；不要把“生成六张”误算成六张都能免费发动。若当前真气不足以支持连续剑气，应保留能量和手牌空间，先用普通攻击、格挡或供气牌过渡。

剑势只在当前回合有效：六种不同剑气从0层开始的结算后层数为 **1→2→4→5→6→8**，下一回合开始清零。每一张剑气都要在发动前检查1点真气，生成本身不计剑式、不增加剑势。

### 六剑的次序按眼前任务排

| 任务 | 顺序原则 |
| --- | --- |
| 爆发杀单体 | 先凝气成锋等增伤，再商阳上易伤，最后少商等主力伤害；敌人能被直接斩杀时优先斩杀。 |
| 清群敌 | 给即将造成威胁的目标上减益，中冲在多个敌人仍存活时兑现群伤；能先杀掉一个出手敌人时不要为了凑剑式拖延。 |
| 需要能量续打 | 少泽只提供虚弱；不要把它当作回能牌。先用供气牌或保留能量，再决定是否发动下一张剑气。 |
| 即将挨重击 | 关冲的实际格挡、少泽的虚弱优先；3层凌波使每段伤害减3，重击仍需实际格挡。 |
| 已有两种剑式 | 第三种打完额外获得1层剑势；若有六脉贯通或六脉图谱，再按各自文本结算。玉佩不提供第三种剑式的抽牌或运气。 |
| 积气充足 | 按斩杀、防守和回能需求安排耗气，根据当前战况决定是否继续积累。 |

打出六种不同剑式才得到第六种奖励；六张少商不算六种。生成剑气不计打出，能力牌也不计技能。凝气成锋只增强本回合，不能留到剑气已经打完才铺。

## 防守、状态牌与连续首领

**格挡与凌波要分开算。** 凌波无叠层上限，每层使每段伤害减少1点，再由格挡吸收剩余伤害，受伤不消耗层数。Burn/Toxic/Wither等可格挡状态伤害和反伤也能减免；毒或卡牌代价等明确失去生命的效果不减免。风过无痕在实际获得层数时立即给格挡。

**状态牌挤抽牌时，先解决眼前生存。** 能消耗或丢弃状态牌的工具要看是否允许选择它、是否真的免掉其结算；不要默认所有诅咒都能移除。遇到不可移除的牌，把它计入抽牌负担，不要白花移除机会。

**三幕四首领是连续资源题。** 第三幕第一首领打赢后，还要面对第二首领。不要为了更好看的当回合伤害，放弃可以少掉二三十血的防守；也不要为了留药而死在眼前这一战。先用药避免关键伤害，再判断能否给下一战留一瓶启动或防守药。

| 对局 | 具体准备 |
| --- | --- |
| 第一幕首领 | 入场前要有能在缺少稀有牌时运作的单体伤害与一张可靠防御；有多个目标时至少保留一个群伤入口。 |
| 第二幕首领 | 不能只靠凌波拖回合。至少准备一条“回能/抽牌→生成或主力攻击”的伤害链，并在非攻击回合积极兑现。 |
| Queen | 旧记录中与火炬敌人同时在场；先判断清掉出手目标能省多少伤害，群伤要同时推进首领生命。不要只防小怪而把首领长期留在高血量。 |
| Aeonglass | 把它当完整第二战准备：首回合就检查神剑门槛，后续没有攻击意图也要检查状态伤害。启动牌、群剑和增伤的顺序要在第一轮排好。 |
| Test Subject | v0.2.1实录中的最终首领。生命阶段变化不等于战斗结束；在多段攻击轮用凌波、关冲和持续格挡稳住，下一回合重新积累剑势后再兑现六剑。 |
