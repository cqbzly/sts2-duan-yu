# 段誉：实现与测试

## v0.5.9 当前状态

当前版本为 v0.5.9。本版将凌波改为每层持续使本回合受到的每段伤害减少1点，多段逐段生效，受伤不消耗层数；最多3层，在自己的下回合开始时清除。移除回合末真气自然流失。北冥初窥运气改为1/2，气沉丹田改为2/3；无意一指伤害16/22，逆脉强攻10/14。剑气归宗与三脉同鸣不再消耗；百脉归炉每消耗1张获得2/3格挡，风过无痕每实际获得1层凌波提供5/7格挡。纳百川运气2/3，涌泉引气升级后获得2能量。部分纯伤害牌小幅下调。独立真气与强制整牌支付、非基础攻击借招、标准起手与六剑规则继续生效。玩法见[实战小抄](cheat-sheet.md)。

本轮96张卡牌数据与图鉴校验、24/24项规则测试、442/442项真实游戏引擎回归通过；Debug与Release构建均0警告、0错误。[v0.5.9 最终引擎报告](https://github.com/cqbzly/sts2-duan-yu/releases/download/v0.5.9/v059-balance-engine-tests.json)。资源检查127/127沿用v0.5.1，本轮未重跑；旧版报告仅作历史基线。

上一版的单种子 A10 通关记录属于历史版本。本版未使用自动策略模拟推断胜率；引擎回归验证牌面、宿主钩子、真气跨回合保留与凌波持续逐段减伤，不替代人工完整 A10 试玩。

引擎日志仍保留Godot RID/ObjectDB/resources退出回收告警；本轮442/442项引擎回归通过。构建无警告不等于运行日志无告警，后续界面体验、远程多人及第三方组合仍需各自验证。当前安装与包记录见[v0.5.9说明](releases/v0.5.9.md)。

目标环境为 Windows《杀戮尖塔2》v0.113.1 public-beta（d09d48e5）与 BaseLib 3.4.8。此前的[环境检查](local-environment-check-2026-11-17.md)记录的是只有设计稿时的状态，不代表当前实现状态。

本轮规则测试23/23、游戏引擎回归235/235、资源加载116项及86张卡牌数据校验通过，Debug与Release构建均0警告、0错误。完整 A10 种子 `DUANYUFULLA10-001` 已通关，新进程从头复现再次胜利；两次四首领记录与最终状态一致，最终77/83生命。当前验证入口见[运行时校验](runtime-verification.md)，完整 A10 方法与证据见[完整流程验证](full-run-validation.md)。这是原生引擎自动策略的完整通关，不是图形界面手工操作记录；旧版单局战斗与历史测试数量不能替代本轮结果。

## 已实现内容

- 自定义角色、选角入口、初始牌组、卡池、遗物池和中文文本。
- 96种卡牌：5种基础牌、83种常规奖励牌、6种衍生剑气及2种不可升级状态牌；前94种含升级。
- 真气获得与支付、凌波逐段减伤、六种剑式、能力与遗物触发、回合计数和战斗状态清理。
- 剑势每回合成长与清零、主动消耗与按张收益、其他已注册角色非基础攻击借招、固定资源收益及两种状态的原生生命周期。
- 8件专属遗物、2个专属事件，包含取消选择、资源复检、奖励去重和玩家归属检查。
- 玩家历史存档扩展，记录已获得的专属遗物与已访问的专属事件。
- 程序化绘制的角色、卡图、图标与场景，以及构建、资源校验、安装和打包脚本。美术为简化风格，未提供专业配音或完整骨骼动画。

卡牌代码位于`src/DuanYu/Cards/`，机制与钩子位于`src/DuanYu/Runtime/`；`data/cards.json`是卡牌名称、费用和描述的数据源。

## 已修复与剩余边界

实测修复了DLL与清单ID不匹配、生成纹理格式前缀缺失、场景纹理类型错误等加载问题；运行时核对并覆盖了开战／回合清理顺序、凌波预览与持续减伤、伤害加成顺序、满手溢出、虚无与保留、事件取消和重复领取边界。

正常界面下的“退出游戏→重开→继续存档”验证尚未完成：本次继续验证时，窗口自动化收到物理Esc停止信号，已停止界面操作。历史序列化自测通过不能替代这个流程。

引擎自测退出时有Godot资源回收提示，详情保留在测试日志中；历史完整流程还出现非致命 `Invalid Task ID`。目前不能保证不存在资源泄漏，也不将这些提示混同为卡牌断言失败。完整A10通关与复现记录属于历史版本；v0.5.9人工完整实战、两台客户端联机、其他游戏分支以及第三方模组组合仍未验证。
