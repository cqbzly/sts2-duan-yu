# v0.5.15：剑气回收与消耗调整

扣脉、不染尘、先退半步、涌泉引气、万流归宗和借招回锋去掉自身的消耗。经脉归一升级后生成可免费打出的升级剑气。气海充盈获得2/3点能量。双脉并进从消耗堆取回至多两张已升级的剑气。

六张牌移除的是自身的消耗关键词。万流归宗和不染尘仍消耗状态牌，借招回锋生成的外门攻击仍带消耗。

经脉归一每回合仍只响应前两次状态牌消耗。升级版生成的剑气整场战斗免真气费，不计为支付；与未升级的能力叠加时分别生成对应版本。双脉并进保留取回牌的费用与升级状态。

设计数据与96种卡牌图鉴已校验，24项规则、464项独立游戏引擎回归、128项资源加载检查全部通过。Debug与Release构建均无警告和错误；Godot退出时仍报告资源回收告警。未运行A10策略模拟。
