# v0.5.4：牌面精简与百川归海调整

本版精简卡牌描述，将能合并的固定格挡改为一次结算，并把已有的回合末真气流失写进初始遗物说明。其他卡牌数值沿用v0.5.3；初始牌组仍为4打击、4防御、北冥初窥、无意一指，共10张。

| 调整 | 当前效果 |
| --- | --- |
| 抱元守一 | 需2真气，一次获得12/16格挡；敏捷与脆弱各修正一次。 |
| 慈悲为怀 | 需3真气，全体20/27伤害、一次16/22格挡、全体2虚弱。 |
| 百川归海 | 基础/升级均1费，运气2/3、获得1/2能量、抽2，消耗。升级不再降为0费。 |
| 琅嬛玉佩 | 每场战斗开始时运气3；你的回合结束时失去1真气。流失为已有角色规则，补说明不会额外扣第二次。 |
| 卡牌说明 | 相同多段伤害用次数表达；缩短费用、时间、状态及借招说明，保留目标、条件和必要关键词。记诵剑谱明确为随机生成。 |

不同伤害段继续分别结算力量、剑势和相关触发；X次数或按消耗张数获得的格挡仍按其机制分别结算。完整基础与升级牌面见[卡牌图鉴](../cards.md)，操作与资源账见[小抄](../cheat-sheet.md)。

自己的回合末流失仍在原生回合末卡牌、气滞、虚无及相关收益全部完成后结算，最低为0，不触发返气、耗气奖励或遗物。真气费用仍在整张牌执行前强制支付。
