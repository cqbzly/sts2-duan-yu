# v0.5.7：借招扩池

北冥借招与借招回锋改从其他已注册角色完整卡池中的全部攻击牌随机生成，高费、X费和有专属资源门槛的攻击都能出现。保留借力、吐纳、踏虚而行、双脉并进和一气贯之的运转改动，撤回v0.5.6对七张纯伤害牌的削弱。

北冥借招和借招回锋从其他已注册角色的完整卡池、初始牌组及归属于这些角色的事件牌中等概率抽取全部攻击牌，包含其他模组角色和注入角色池的攻击；不按费用、稀有度、专属资源或特殊打出条件预筛，同次生成不重复。候选数量随游戏版本与启用的模组变化。高费、X费和依赖其他角色资源的攻击都可能出现。生成牌添加消耗，固定能量费在本回合或首次打出前为0；X费、星星等其他资源费用和原生打出条件仍然生效。生成使用战斗随机数，只修改生成实例，不改写原始模板。

卡面正文删除重复的“需N点真气”前缀，费用仍显示在专属费用标记中；强制付气规则不变。

借力仍为1费抽2/3弃1的技能；吐纳抽1并运气1/2；踏虚而行获得1层凌波并抽1/2；双脉并进为1费消耗，取回至多1/2张已消耗剑气，保留其升级；一气贯之仍需3气、造成16/22伤害并抽2。初始牌组、玉佩、真气支付及回合末流失规则不变。
