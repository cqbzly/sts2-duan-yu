# v0.5.2：初始牌组数量修正

段誉现在以4张打击、4张防御、1张北冥初窥和1张无意一指开始游戏，共10张。打击仍为1费造成6点伤害，防御仍为1费获得5点格挡；新增第4张打击，并将凌波初步移出初始牌组。凌波初步保留卡牌实现和图鉴条目，卡牌总数仍为96种。

其他卡牌数值与机制保持 v0.5.1：琅嬛玉佩只在每场战斗开始给予3点真气；真气使用左下角独立图标、名称与计数器，所有真气费用牌必须在整张牌执行前足额支付。能量免费和独立自动打出仍需支付真气，同次原生重放只支付一次。
