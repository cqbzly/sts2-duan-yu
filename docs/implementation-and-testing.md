# 段誉 v0.1.1：实现与测试记录

本版本已经包含可加载的角色模组程序，处于开发预览阶段。目标环境为 Windows《杀戮尖塔2》v0.113.1 public-beta（d09d48e5）与 BaseLib 3.4.8。此前的[环境检查](local-environment-check-2026-11-17.md)记录的是只有设计稿时的状态，不代表当前实现状态。

## 已实现内容

- 自定义角色、选角入口、初始牌组、卡池、遗物池和中文文本。
- 86种卡牌及其升级：5种基础牌、75种常规奖励牌、6种衍生剑气。
- 真气获得与支付、凌波逐段减伤、六种剑式、能力与遗物触发、回合计数和战斗状态清理。
- 8件专属遗物、2个专属事件，包含取消选择、资源复检、奖励去重和玩家归属检查。
- 玩家历史存档扩展，记录已获得的专属遗物与已访问的专属事件。
- 程序化绘制的角色、卡图、图标与场景，以及构建、资源校验、安装和打包脚本。美术为简化风格，未提供专业配音或完整骨骼动画。

卡牌代码位于`src/DuanYu/Cards/`，机制与钩子位于`src/DuanYu/Runtime/`；`data/cards.json`是卡牌名称、费用和描述的数据源。

## 已修复与剩余边界

实测修复了DLL与清单ID不匹配、生成纹理格式前缀缺失、场景纹理类型错误等加载问题；运行时核对并覆盖了开战／回合清理顺序、凌波预览与真实消耗、伤害加成顺序、满手溢出、虚无与保留、事件取消和重复领取边界。

正常界面下的“退出游戏→重开→继续存档”验证尚未完成：本次继续验证时，窗口自动化收到物理Esc停止信号，已停止界面操作。历史序列化自测通过不能替代这个流程。

引擎自测退出时有Godot资源回收提示，详情保留在测试日志中；目前不能保证不存在资源泄漏，也不将这些提示混同为卡牌断言失败。完整通关平衡、两台客户端联机、其他游戏分支以及第三方模组组合仍未验证。

本地安装包为`dist/DuanYu-0.1.1.zip`，包含Release DLL、模组清单和安装说明；不含游戏程序集、用户存档、测试副本或开发工具。安装方法见[安装说明](installation.md)。
