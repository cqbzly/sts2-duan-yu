# v0.5.11：头环升级

琅嬛玉佩现在可通过奥罗巴斯的升级初始遗物选项，替换为段誉专属头环。

**头环：每场战斗开始时，运气5。每个自己的回合开始时，运气1。** 首回合也获得1气，因此每场战斗开局共6气，之后每回合补1气，上限仍为9。

这是段誉的专属升级遗物，不改变原版无效果的Circlet。头环不进入普通奖励或商店；取得或替换时不补发当前战斗的开场真气。其余卡牌与机制沿用v0.5.10。

旧存档中尚未领取、仍指向原版Circlet的奥罗巴斯升级玉佩选项，加载后会显示并领取专属头环；已持有的原版头环保持原样。
