# v0.5.12：头环回合末回气

**头环：每场战斗开始时，运气5。每回合结束时，运气1。**

每回合的1点真气改到自己的回合结束时获得。首回合开始有5气，无消耗时首回合结束有6气；上限仍为9。头环仍通过奥罗巴斯升级琅嬛玉佩取得，不进入随机奖励或商店。旧未领取选项兼容沿用v0.5.11，其余卡牌与机制不变。

头环在手牌回合末扣气、虚无消耗和弃牌处理后回气；9气带一张气滞且无其他收益时，回合结束后为8气。
