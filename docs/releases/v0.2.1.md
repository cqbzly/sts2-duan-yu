# v0.2.1：输出、回能与六脉连携强化

本版本针对 v0.2.0 完整 A10 自动测试连续败局，以及玩家反馈的输出、能量和剑气联动不足，继续强化角色。它是本地候选版本，GitHub 与 Steam 工坊的已上传文件尚未更新。玩法小抄见[段誉通关秘籍](../cheat-sheet.md)。

## 主要改动

- 琅嬛玉佩在战斗开始提供3真气；每回合首张技能结算后提供2真气与1能量。首次打出第三种不同剑气后抽1并运气2，首次打出第六种后获得1能量并运气3。
- 打击、防御、北冥初窥、无意一指及多张普通攻击、群伤和产气牌加强，降低初期成型压力。
- 六种剑气分别加强伤害、易伤、群伤、格挡、抽牌产气和虚弱回能；少泽的回能门槛降为1真气。
- 六脉神剑为1费、耗气3，提供16格挡并生成六种剑气；升级后提供22格挡并生成六种升级剑气。
- 北冥神功为1费，升级0费；每回合前两次成功耗气返2气，首次另回1能量。百川归海升级后0费，获得8真气、3能量并抽3张牌，然后消耗。
- 无形剑阵打出时立即选择两种不同剑气，后续每回合生成一张；六脉贯通、守拙、易经心法、无相之境和高伤害金卡同步增强。
- 新增剑势：每层令六种剑气每段伤害增加1点，最高12层，跨回合保留、战后清空。每张剑气结算后叠1层，第三种剑额外叠1层，第六种额外叠2层；多段攻击在当前牌完整结算后才叠层。
- 剑随心转改为随机生成两种不同剑气；书生意气在原抽牌后随机得到真气、能量或剑势之一；大梦初醒在原效果后随机得到三类收益中的两种。升级增强对应收益，随机使用原生种子流，普通预览不推进随机序列。

回能均在原始费用支付后结算。每回合门槛按实际出牌计数，升级、复制、Replay 和重复回调不能重置已触发次数。真气上限仍为9，剑气仍为0费、消耗、虚无。
