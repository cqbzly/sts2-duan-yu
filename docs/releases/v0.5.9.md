# v0.5.9：凌波与资源平衡

凌波每层使本回合受到的每段伤害减少1点，包括多段，受伤不消耗层数；最多3层，在自己的下回合开始时清除。减免可格挡的状态伤害与反伤，明确“失去生命”的效果不受影响。风过无痕改为每实际获得1层凌波给5/7格挡，满层不触发。

移除回合末自然失去1点真气，真气跨回合保留；玉佩仍只在战斗开始运气3。气滞在手牌回合末失去2气的效果保留。

借招继续纳入其他已注册角色的全部非基础攻击，包括高费、X费、角色归属事件和模组注入牌，排除全部Basic攻击。真气独立资源与强制支付不变，初始牌组仍为4打击、4防御、北冥初窥与无意一指，共10张。
