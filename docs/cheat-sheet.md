# 段誉 v0.5.8 · A10 实战小抄

本页面向 v0.5.8：初始牌组为4张打击、4张防御、北冥初窥与无意一指，共10张，凌波初步不再随开局提供。真气是左下角独立资源，所有真气费用牌都必须先付足气才能打出整张牌；六剑各需1气。本版保留五张运转牌的重做：借力改为抽2/3弃1的技能，吐纳改为抽1并运气1/2，踏虚而行改为1层凌波加抽1/2，双脉并进改为从消耗堆取回至多1/2张剑气，一气贯之改为16/22伤害并抽2。撤回七张纯伤害牌在v0.5.6的削弱，北冥借招与借招回锋改从其他已注册角色完整卡池中的非基础稀有度攻击牌随机生成，高费及有专属资源门槛的攻击也能出现。自己的每个回合末全部原生牌与消耗收益结算后失去1真气，最低0，不算支付。凌波每层减伤1，剑势回合开始清零且上限8，剑气生成随机无放回，包含回风取物、琅嬛寻卷、借招回锋、万流归宗与六脉齐发。常规奖励池为23张普通、38张罕见和22张稀有，共83张；本版不以自动策略采样估计 A10 胜率。

## 六剑速查

六种都是0费攻击，消耗、虚无；每次发动需支付1点真气。表内“基础/升级”分别表示未升级与升级值。剑势每层为剑气加1伤害，之后再应用易伤、虚弱等修正；力量和其他剑气增伤也会改变实际伤害。

| 剑气 | 基础 / 升级伤害 | 耗气与附效 | 先想到的用途 |
| --- | --- | --- | --- |
| 少商 | 7 / 10，单体 | 一次伤害，剑势加成一次。 | 主力单体输出；先吃到易伤与增伤。 |
| 商阳 | 3 / 5，单体 | 伤害后给予1层易伤，升级不增加层数。 | 先手破防；不能靠本张回气。 |
| 中冲 | 5 / 7，全体 | 每个敌人各受一次伤害。 | 群怪仍在场时兑现群伤。 |
| 关冲 | 3 / 5，单体 | 获得3 / 5格挡。 | 即时防守，真气支出固定。 |
| 少冲 | 2 / 3，单体 | 抽1张。 | 续手；先腾手牌空间。 |
| 少泽 | 2 / 4，单体 | 伤害后给予1层虚弱，升级不增加层数。 | 降低来伤；别把最后1气花掉。 |

急用顺序：**要爆发先商阳，要减伤给少泽留1气，要防守优先关冲；凝气成锋必须在这些剑之前。** 凝气成锋不再供气，只提供本回合剑气伤害+2/3；指法纯熟为每回合前2张剑气伤害+2/3。已有第3/第6种奖励时，再把即将到达的门槛收入资源账。

## 剑势：先铺路，再兑现伤害

剑势上限8，每回合开始清零、战后清空。每层使六种剑气伤害加1，普通打击、无意一指等非剑气攻击不享受。六剑对每个目标只造成一次伤害，力量和剑势各加一次。安全时让少商接在铺易伤和抽牌的剑后面，中冲用于清理群敌。

从0层开始连续打出六种不同剑气，打完后的层数为 **1→2→4→5→6→8**；第六剑使用打出前的6层，不能提前按8层计算。Replay 每次真实再次打出并结算都加1层，但同一种剑仍只算一种。满8层后继续打剑不再增加层数；无需为了成长放弃眼前斩杀或承受不必要伤害。

剑势奖励与玉佩分开算：第三种和第六种剑只带来剑势额外+1；六脉贯通或六脉图谱若在场，再按它们自己的文本结算。书生意气、大梦初醒与异种真气直接加剑势，不增加剑式数量；回合结束后剑势不保留。

**金卡选择也看缺口。** 六脉神剑能提供整套攻防，百川归海同时补气、能量和手牌，北冥神功适合每回合都能成功耗气的牌组。拿到一张核心后，优先补它所缺的抽牌、伤害或防守，而不是继续堆同类启动牌。

**薄牌组的目标是准时抽到好牌。** 有足够输出前不要为删牌牺牲全部战力；有替代牌后再删基础牌。每次奖励只问一句：这张牌能解决下一段路线的哪一个问题？答不出就跳过。已有群伤仍要保留单体斩杀；已有凌波仍要保留实际格挡。

## 北冥炼化：先打核心，再清手

| 卡牌 | 主动消耗方式 | 用途 |
| --- | --- | --- |
| 逆运经脉 | 1费，选耗1张其他手牌，固定抽3/4、运气1/2；若消耗状态牌再抽1张；本牌不自耗。 | 气滞或异种真气可以换成额外过牌，普通废牌仍只提供基础收益。 |
| 内息归元 | 1费、自耗，选耗至多3/4张；每实际消耗1张运气1、格挡2/3。 | 多张废牌换眼前防守；选择0张也合法，但不凭空给按张收益。 |
| 百脉归炉 | 2费能力，每消耗1张获得1/2格挡；消耗两种专属状态时各额外运气1。 | 主动清理、剑气自耗和虚无都会形成防守；状态还能补回部分真气。 |
| 不染尘 | 2费、消耗；清虚弱/脆弱/中毒，7格挡，消耗手中所有状态，每张运气1、抽1。 | 保留普通好牌，集中清状态；异种真气也是状态，会一起被清掉。 |

**对付沙漏与 Wither：** 先核对原生状态的回合末结算，再打出当前值得保留的能力、供气和防守。手里剩下状态与低价值牌时，用生生不息一次换成剑；只有一张状态就用逆运经脉，需要眼前格挡就用内息归元。把状态提前消耗，才能免掉它之后的手牌结算；凌波不能抵消非攻击状态伤害。

**两种专属状态都能炼化。** 蓄势一击把气滞放进弃牌堆；气滞不可打出、虚无，只有留在手牌到回合末才先扣2气再消耗，扣气不触发北冥退款。北冥借招把异种真气放进弃牌堆；借招回锋与经脉归一直接放入手牌。抽到后花1能量固定换2气、1剑势、抽1并消耗。异种真气属于状态；两者均不可升级。自己的回合末全部虚无消耗收益结算后还会自然流失1气；这与气滞扣2气叠加，也不触发退款或国印。玉佩只在战斗开始提供3气，不追加出牌收益。

北冥借招和借招回锋从其他已注册角色的完整卡池及归属于这些角色的事件牌中，等概率抽取非基础稀有度攻击牌，包含其他模组角色和注入角色池的攻击；排除全部基础稀有度（Basic）攻击，包括各角色的打击。不按费用、其他稀有度、专属资源或特殊打出条件预筛，同次生成按牌ID去重。候选数量随游戏版本与启用的模组变化。高费、X费和依赖其他角色资源的攻击都可能出现。生成牌添加消耗，固定能量费在本回合或首次打出前为0；X费、星星等其他资源费用和原生打出条件仍然生效。生成使用战斗随机数，只修改生成实例，不改写原始模板。详细规则见[机制说明](mechanics.md)。借招回锋造成12/17点伤害并把异种真气直接放入手牌，北冥借招仍把异种真气放入弃牌堆。

## 出牌顺序：把回能真正接起来

### 玉佩只提供开场真气

玉佩只在战斗开始给3气。之后技能必须独立支付能量和耗气，不能把玉佩当作回能或额外抽牌来源；0费技能仍按自身牌面结算。

玉佩没有后置返气，因此手里只有2气时，六脉神剑会因3气费用无法打出，能量和手牌都不改变；先使用能产气的牌，再规划真气费用牌。

### 攻击生成器仍按攻击牌计算

当前的关冲护体是1费攻击：8/12伤害、4/6格挡，再生成未升级关冲。生成的关冲需要额外1点真气才能发动；剑气本身不再返气或回能。附带格挡或剑气不会改变生成器的攻击类型，计算时先确认当前真气和手牌空间。

少商起势、商阳点穴、中冲破阵、少冲探路、少泽回环也要重新看攻击类型。六脉神剑、记诵剑谱与剑随心转仍是技能；它们生成的剑气仍需按当前真气和随机剑式重新计算。双脉并进也是技能，但现在从消耗堆取回原有剑气，应先看消耗堆中有哪些剑式和升级。

### 先装北冥，再花真气

北冥神功是能力牌，费用1、升级后0；每回合前两次成功耗气各返1气，首次另回1能量。计划本回合多次耗气时，应在第一次耗气前打出。若此前已经成功耗气，后装能力不会补发过去收益或重置次数。守拙每回合开始供2气，首剑回能仍为1；六脉贯通的第三/第六种门槛各供1气，抽牌和回能次数不变。

耗气先支付，附加效果完成后才返还。不能拿未来返气支付眼前的门槛；也不能把“每回合前两次”算成每张剑都返气。

### 资源账例：六剑需要逐张支付真气

假设开局3能量、3气，先花1能量打北冥初窥，按牌面获得5格挡和2气，此时剩2能量、5气；再用六脉神剑支付2能量和3气，剩余2气最多支持2张各需1气的剑气。若两张都打出且没有其他供气，结束回合时为0气；若一张都不打，原生回合末收益结算后2气自然流失至1。玉佩只在战斗开始给3气，不会因打出技能追加资源；剑气不会返气、回能或提供运气。该例假设已获得六脉神剑，它不属于初始牌组。

六脉神剑结算后，优先打关冲维持格挡或打少泽施加虚弱，取决于敌人意图；不要把“生成六张”误算成六张都能免费发动。若当前真气不足以支持连续剑气，应保留能量和手牌空间，先用普通攻击、格挡或供气牌过渡。

剑势只在当前回合有效：六种不同剑气从0层开始的结算后层数为 **1→2→4→5→6→8**，下一回合开始清零。每一张剑气都要在发动前检查1点真气，生成本身不计剑式、不增加剑势。

### 六剑的次序按眼前任务排

| 任务 | 顺序原则 |
| --- | --- |
| 爆发杀单体 | 先凝气成锋等增伤，再商阳上易伤，最后少商等主力伤害；敌人能被直接斩杀时优先斩杀。 |
| 清群敌 | 给即将造成威胁的目标上减益，中冲在多个敌人仍存活时兑现群伤；能先杀掉一个出手敌人时不要为了凑剑式拖延。 |
| 需要能量续打 | 少泽只提供虚弱；不要把它当作回能牌。先用供气牌或保留能量，再决定是否发动下一张剑气。 |
| 即将挨重击 | 关冲的实际格挡、少泽的虚弱优先；一段攻击最多消耗1层凌波，堆到3层也只减该段1点。 |
| 已有两种剑式 | 第三种打完额外获得1层剑势；若有六脉贯通或六脉图谱，再按各自文本结算。玉佩不提供第三种剑式的抽牌或运气。 |
| 快满9气 | 先兑现有价值的耗气再补气；但不要因此错过易伤、增伤或唯一回能点。 |

打出六种不同剑式才得到第六种奖励；六张少商不算六种。生成剑气不计打出，能力牌也不计技能。凝气成锋只增强本回合，不能留到剑气已经打完才铺。

## 防守、状态牌与连续首领

**格挡与凌波要分开算。** 凌波最多3层，每层只抵一段正数攻击的1点伤害，且先于格挡消耗。Wither、Burn、Toxic 等非攻击状态伤害不消耗凌波；按原生规则可被格挡的部分必须留实际格挡。敌人意图显示0，也不代表本回合没有状态伤害。直接失去生命则另按该效果规则处理。

**状态牌挤抽牌时，先解决眼前生存。** 能消耗或丢弃状态牌的工具要看是否允许选择它、是否真的免掉其结算；不要默认所有诅咒都能移除。遇到不可移除的牌，把它计入抽牌负担，不要白花移除机会。

**三幕四首领是连续资源题。** 第三幕第一首领打赢后，还要面对第二首领。不要为了更好看的当回合伤害，放弃可以少掉二三十血的防守；也不要为了留药而死在眼前这一战。先用药避免关键伤害，再判断能否给下一战留一瓶启动或防守药。

| 对局 | 具体准备 |
| --- | --- |
| 第一幕首领 | 入场前要有能在缺少稀有牌时运作的单体伤害与一张可靠防御；有多个目标时至少保留一个群伤入口。 |
| 第二幕首领 | 不能只靠凌波拖回合。至少准备一条“回能/抽牌→生成或主力攻击”的伤害链，并在非攻击回合积极兑现。 |
| Queen | 旧记录中与火炬敌人同时在场；先判断清掉出手目标能省多少伤害，群伤要同时推进首领生命。不要只防小怪而把首领长期留在高血量。 |
| Aeonglass | 把它当完整第二战准备：首回合就检查神剑门槛，后续没有攻击意图也要检查状态伤害。启动牌、群剑和增伤的顺序要在第一轮排好。 |
| Test Subject | v0.2.1实录中的最终首领。生命阶段变化不等于战斗结束；在多段攻击轮用凌波、关冲和持续格挡稳住，下一回合重新积累剑势后再兑现六剑。 |
