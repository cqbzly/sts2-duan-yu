# v0.5.1：独立真气与强制费用

真气现在是段誉自己的资源。左下角计数器显示真气专属图标和当前值/9，悬停说明显示“真气”；真气为0时仍可见。获得、支付和失去真气都不再读写原生辉星。

所有21种标注真气费用的卡牌，包括六种衍生剑气，必须在整张牌执行前支付足额真气。真气不足时不能打出，不会支付能量、移动手牌、结算部分攻防或增加出牌次数。原先“耗气N：追加效果”的牌改为明确的整牌费用，原有数值保留。

能量免费不会免除真气费用，独立触发的自动打出也需支付。原生重放共享同一次出牌的费用，返气、首次耗气抽牌、天龙念珠和大理国印只按实际的一次支付触发。

回归覆盖基础及升级版本的费用不足、足额与单次扣费，自动打出与重复使用、重放、资源隔离、费用图标与说明、玩家隔离及取消出牌清理。
