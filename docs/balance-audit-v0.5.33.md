# 段誉卡牌平衡审查

后续采纳的调整见 [v0.5.34 更新记录](releases/v0.5.34.md)。

以 v0.5.32 的 97 种卡牌为基线。覆盖 83 种常规奖励、5 种基础牌、1 种先古牌、6 种衍生剑气和 2 种状态。按功能比较基础版和升级版，同时计入能量、真气、生命、消耗、手牌空间和生效时点。下文的斜线分别表示基础版与升级版。结论来自卡牌数据和实际结算，胜率、选牌率及联机实战表现尚待玩家对局验证。

## 已调整的借招回锋

原版北冥借招用 1 费拿两张随机攻击，借招回锋用 2 费只拿一张同池攻击。回锋另外造成 12/17 点伤害并将异种真气直接加入手牌，但两张牌都可能借到当回合用不了的 X 费牌或专属资源牌，回锋没有第二个选项。

v0.5.33 的回锋先打 **12/17**，再从 **3 张不同的随机外门攻击**里选 **1 张**。借来的牌本回合固定能量费为 0、具有消耗，然后获得手牌异种真气。候选范围与北冥借招一致，即其他角色的全部非基础攻击，可以选高费、事件牌或 X 费牌。升级展示升级招式。

北冥借招适合手牌空间充足、希望用 1 费带来两次进攻的回合。回锋能先打确定伤害，再根据敌人数、斩杀线和剩余资源选招，也能给百脉归炉提供消耗次数。回锋保留 2 费，给 1 费、14/19 点固定伤害且直接产状态的蓄势一击留下低费出手的空间。

## 接近但有独立用途的牌

| 牌组 | 实际取舍 |
| --- | --- |
| 气海充盈／百川归海／涌泉引气 | 气海与百川净增能量同为 1/2、产气同为 2/3，百川免前置能量并抽 2，是稀有牌对罕见牌的上位。涌泉用 3/2 生命换当天资源，可循环，适合急需能量的回合。 |
| 借力／吐纳／气沉丹田／读书明理 | 借力先抽再弃，可处理已经抽到的气滞或主动设置弃牌堆。吐纳用能量换牌和固定 2 气。气沉省能量，读书用气滞换更多牌。 |
| 回澜取物／逆运经脉／回风取物／琅嬛寻卷 | 回澜消耗手牌后能取回弃牌堆状态，北冥借招放在弃牌堆的异种真气是自然目标。逆运适合立刻把手牌状态换成过牌。回风找弃牌堆任意牌，琅嬛从抽牌堆找非状态，两张自身消耗。回澜在无状态牌可取时明显偏弱。 |
| 内息归元／万流归宗／不染尘 | 内息可挑多张任意手牌换气和格挡。万流先付能量 X，再清状态并按实际张数回能，能量或状态少时收益都会下降。不染尘负责清减益与清空手牌状态。 |
| 绵掌／斜行避势，游身／借隙回身 | 后者在各自的一组里给得更多，也会塞气滞。囤气时，气滞可能吃掉 2 真气并占一格手牌。有稳定清理能力时，罕见牌的优势会扩大。 |
| 记诵剑谱／剑随心转／无形剑阵／双脉并进 | 分别是 0 费单次补剑、1 费一次性补两种、持续供剑、定向回收升级剑气。剑随心转在长战容易被剑阵抢位置，若需强化，可优先随机补本回合还没打过的剑式，仍然只给两张。 |
| 六脉神剑／三脉同鸣／剑气归宗 | 神剑要求气和手牌空间才能兑现六种剑气。三脉提供即时单体伤害，归宗提供群伤并升级手里已有的剑气。归宗升级的独立收益主要是群伤 15→20，因为基础版也会升级自己刚生成的剑气。 |
| 无相之境／六脉贯通／指法纯熟／凝气成锋 | 无相看前三张剑气，贯通看不同剑式，指法提供持续增伤，凝气只加当前回合。六脉齐发吃剑气增伤，但它的多段结算不会凑剑式。 |
| 天南一指／六脉齐发／六脉真传 | 天南以 5 气打固定伤害，可循环且保留多余的气。齐发花光真气，吃每段增伤后斩杀。真传花光真气换持续力量，适合后续还有足够攻击的战斗。 |
| 先退半步／倒踩七星／临风独立 | 先退本轮减伤、下轮格挡，倒踩把凌波分配到两轮并延迟抽牌，临风集中在当前回合扛多段。 |
| 援手／同行／舍身相护 | 联机中分别是出牌者补气、指定角色补手、花血提高即时救援。目标各自需要的资源决定选择。 |

## 组合观察

- **风过无痕+ × 凌波微步。** 两个能力到位后，前三张技能可额外提供 3 层凌波和 21 格挡。临风独立+本身的 3 层还能触发另 21 格挡。遇到多段攻击时减伤和格挡同时放大，值得观察长战里的防守投入。
- **守拙 × 真气护体。** 守拙每轮运气 2，护体按回合结束时的全部真气挡伤。囤气时每轮格挡会继续增长。易经心法从下轮开始给固定格挡，出牌时仍可花气，因此更适合高频支付。
- **剑势 × 六脉齐发。** 已有 8 剑势并剩 5 气时，齐发+打 5 段各 16，共 80 点伤害，尚未计入力量、虚弱与易伤。前置投入和用尽真气本身就是代价，建议比较完整回合的总资源。
