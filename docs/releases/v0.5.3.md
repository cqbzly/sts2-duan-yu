# v0.5.3：真气与六剑再平衡

本版降低多数供气牌及部分遗物的产气，压低六剑伤害、格挡及升级减益收益，让真气支出需要更明确的取舍。初始琅嬛玉佩仍在每场战斗开始给予3点真气，打击仍为6/9伤害、防御仍为5/8格挡，初始牌组仍为4打击、4防御、北冥初窥、无意一指，共10张。其他非剑气攻击的伤害不变。

每个自己的回合结束，先完成原生回合末牌、气滞、虚无消耗及相关收益，再失去1点真气，最低为0。该流失不算支付，不触发北冥返气、遗物或其他耗气奖励；敌方和队友回合不扣。气滞自身仍扣2气，与最后的1点流失叠加。剑气牌继续具有消耗、虚无；剑势仍在自己的下回合开始清零，上限8，每张剑气加1层及第三、第六种的额外层数保持不变。

| 剑气 | 基础效果 | 升级效果 |
| --- | --- | --- |
| 少商 | 5伤害，再造成2伤害。 | 7伤害，再造成3伤害。 |
| 商阳 | 3伤害，1层易伤。 | 5伤害，1层易伤。 |
| 中冲 | 全体3伤害，再对全体造成2伤害。 | 全体4伤害，再对全体造成3伤害。 |
| 关冲 | 3伤害，3格挡。 | 5伤害，5格挡。 |
| 少冲 | 2伤害，抽1张。 | 3伤害，抽1张。 |
| 少泽 | 2伤害，1层虚弱。 | 4伤害，1层虚弱。 |

六剑仍各需1点真气。所有真气费用都在整张牌执行前强制支付，费用不足时整张牌不能打出；能量免费和独立自动打出仍需支付，同次原生重放只支付一次。

供气调整包括北冥初窥、吐纳、吸纳等基础循环牌；记诵剑谱、中冲破阵、凝气成锋与袖底藏锋移除附送真气。北冥神功每回合前两次支付后的返气由2降至1，首次回能保持1；百川归海供气由5/7降至3/4，能量和抽牌不变；异种真气由3气、2剑势降至2气、1剑势，仍抽1并消耗。凝气成锋与指法纯熟的剑气增伤同步降低。完整牌面见[卡牌图鉴](../cards.md)。
