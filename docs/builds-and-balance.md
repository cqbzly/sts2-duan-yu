# 段誉：构筑指南与平衡验证

版本 v0.5.5。卡池共96张，普通23张、罕见38张、稀有22张，另有5张基础、6张衍生和2张状态牌；常规奖励池共83张。本文说明攻击、剑气、防守与主动消耗如何组合；具体数值以[卡牌图鉴](cards.md)为准。旧版的单种子 A10 结果不外推当前版本胜率；当前版本仍需人工实机测试。逐步资源账、抓牌与沙漏状态处理见[A10 实战小抄](cheat-sheet.md)。

## 基础循环

真气上限9，每个自己的回合末先完整结算原生回合末牌、气滞、虚无消耗及相关收益，再失去1气，最低0，剩余跨回合保留。自然流失不算支付，不触发返气或耗气奖励，敌方和队友回合不扣本人的气。凌波上限3，每层对一段攻击减伤1。六种剑气均为0费、消耗、虚无，必须支付1真气才能发动，通过战斗 RNG 无放回生成。三条路线共用这些组件，选牌应解决当前缺口，不要求从开局只走一个标签。

剑势上限8，每回合开始清零，每层使六种剑气伤害增加1。每张剑气结算后加1层，第3种不同剑气每回合额外加1层、第6种额外加1层。持续生成只服务当前回合的输出；普通攻击不受此加成，不能为了叠势放弃当前可以结束战斗的斩杀。

琅嬛玉佩只在战斗开始运气3。首张技能和第3/第6种剑式的额外收益由六脉贯通、守拙等其他卡牌或遗物独立提供，不能把玉佩当作持续回能来源。

角色的资源回路需要同时有产气、可付费用、可打手牌和有效输出。持续加气却不花气会溢出；反复抽牌却没有能量也无法解决敌人。优先建立能在当前战斗兑现的组件，再补长期能力。

## 攻击不再只是等待六剑

83张常规牌现在包含35张攻击。无意一指为1费、2气，一次造成20/28伤害；以气催劲为1费、3气，一次造成30/42伤害；一气贯之为1费、3气，一次造成33/45伤害。真气不足时这三张都不能打出。指风为1费全体10/14；内力震荡为3费、3气，对目标造成54/72伤害，对其他敌人造成22/29伤害；六脉齐发需X能量和3气，对全体一次造成7/10×(X+1)伤害，让非六剑构筑也有直接处理单体与群敌的入口。

少商起势、商阳点穴、关冲护体、中冲破阵、少冲探路、少泽回环等生成器现在先造成伤害，再保留原有附效。它们属于攻击，不再为玉佩或凌波微步提供技能次数。先用北冥初窥、书生意气、逆运经脉等真正技能启动资源，再决定要留多少真气给高伤攻击；不能继续按旧版“所有生成器都返1能”算账。

## 北冥蓄势

**目标：** 用技能和攻击供气，选择把真气留给蓄势一击，还是支付耗气立即换取伤害或格挡。

| 任务 | 可用组件 | 抓牌判断 |
| --- | --- | --- |
| 早期供气与输出 | 北冥初窥、吐纳、吸纳、无意一指、借力 | 开局已有供气与耗气出口；补牌要提高抽到有效攻防的机会。 |
| 一次性加速 | 气海充盈、涌泉引气、百川归海 | 有后续能打出的牌时拿取；涌泉的失去生命不能被格挡或凌波抵消。 |
| 资源兑现 | 以气催劲、蓄势一击、内力震荡、天南一指 | 天南一指现在耗气5；选择留气还是花气之前，先算能否少让敌人行动一轮。 |
| 持续衔接 | 北冥初成、北冥神功、读书明理 | 能力要在相关首次触发之前装好，不能补发已经过去的收益。 |
| 保命 | 抱元守一、纳百川、慈悲为怀 | 当伤害无法结束战斗时，把气用于减少实际生命损失。 |

北冥神功费用1、升级后0；每回合前两次成功支付真气各返1气，首次另回1能量。它提供有限周转，不能支付眼前不够的门槛，回合末自然流失也不会触发返气。蓄势一击为2费16/23基础伤害，每点气再加1；满9气为25/32基础伤害，不扣真气，随后向弃牌堆加入气滞。先打蓄势再支付真气通常保留更多输出，但遇到眼前斩杀或防守时仍需重新排顺序。

## 凌波游身

**目标：** 用凌波处理多段攻击，用实际格挡处理大伤害与可被格挡的状态伤害，再用少量强攻击尽快收尾。

| 任务 | 可用组件 | 抓牌判断 |
| --- | --- | --- |
| 当回合防守 | 掠影步、抱元守一、关冲护体、临风独立 | 一段重击只消耗1层凌波；此时直接格挡比多余层数更有价值。 |
| 降低敌方输出 | 绵掌、斜行避势、少泽剑气、慈悲为怀 | 根据实际攻击目标与段数分配虚弱，不把它当作格挡。 |
| 跨轮准备 | 倒踩七星、先退半步、易经心法 | 新回合格挡与抽牌为下一轮服务；不要用它们代替眼前致命伤害的防守。 |
| 结束战斗 | 回身一指、以气催劲、指风、生成的剑气 | 防御流也需要单体和群体伤害，不能靠无限拖延应对成长敌人。 |

Wither、Burn、Toxic 等非攻击状态伤害不触发凌波，按宿主规则可被格挡的部分仍需实际格挡。敌人意图没有攻击，也要检查状态牌与持续伤害。直接失去生命另按效果规则处理。

## 六脉变招

**目标：** 根据敌人和手牌安排随机剑式，先铺增伤与易伤，再把六剑的伤害、防御和抽牌串起来；六剑本身不返气或回能。

| 任务 | 可用组件 | 抓牌判断 |
| --- | --- | --- |
| 随机补剑 | 记诵剑谱、双脉并进、剑随心转、三脉同鸣 | 生成结果由战斗 RNG 决定；不能保证指定防守或减益剑，先确认真气和手牌空间。 |
| 整套六剑 | 六脉神剑 | 基础/升级均2费、耗气3；分别给8/11格挡，并随机生成未升级/升级六剑。 |
| 持续生成 | 无形剑阵 | 打出时随机生成1张剑气，之后每回合开始再随机生成1张；升级生成升级剑气。注意回合开始手牌空间。 |
| 伤害提高 | 凝气成锋、指法纯熟 | 增伤在剑气之前打；指法纯熟每回合只增强前2张剑气，基础/升级加2/3伤害。 |
| 当回合成长 | 剑势、书生意气、大梦初醒、异种真气 | 先打出有用剑气积累层数；剑势回合开始清零，固定收益受8层上限限制。 |
| 回能与抽牌 | 六脉贯通、守拙、少冲剑气 | 三剑/六剑门槛和首剑触发分开记；少冲只抽牌，实际抽到新牌后重新规划。 |
| 剑气防守 | 关冲剑气、无相之境 | 关冲提供一次格挡，无相之境只奖励前3张剑气；按实际触发次数计算。 |

六脉神剑升级会把整套产物升级，是有稳定供气后优先考虑的升级。基础神剑与升级神剑仍需留出六张手牌空间，并且要支付3气；不能只看总收益，不看满手会丢到弃牌堆的那几张剑。

面对高出牌次数惩罚和反伤，六剑是六次独立攻击；不要因为零费就机械打完。状态、敌人意图和击杀条件变化后，应重新决定是否继续。

## 固定资源与随机招式

书生意气先抽2/3张，当前至少5气时再抽1，然后固定运气1、获得1层剑势，不提供能量。自身2费（升级1费）；额外抽牌条件仍必须在本牌运气前满足。记诵剑谱、中冲破阵与袖底藏锋不再附带供气；凝气成锋也不再供气，只使本回合剑气伤害+2/3，指法纯熟则只为每回合前2张剑气伤害+2/3。

大梦初醒1费、消耗，先失去全部格挡并抽3/4张，再固定运气2/3、获得1能量、获得2/3剑势。优先在尚未建立格挡时使用；固定回能不等于免费防守，仍要用后续牌把丢掉的格挡补回来。已获得的剑势不回溯提高此前打出的剑气。

随机性集中于招式：剑随心转的两种不同剑、北冥借招的两种不同外门攻击，以及生生不息按消耗数生成的随机剑。前两者同次不重复，生生不息允许重复，不能把“生成六张”误当成必定凑齐六种剑式。

## 北冥炼化与借招

这条路线用主动消耗换取下一步行动，处理状态牌时尤其有价值。它从罕见牌逆运经脉、内息归元就能开始，不要求先拿齐金卡。逆运经脉消耗状态牌时额外抽1张；百脉归炉每耗一张给1/2格挡，消耗气滞或异种真气时额外运气1，把主动清理、剑气自耗与虚无消耗连成防守和回气；技能、攻击和状态牌的消耗都可以贡献，但同一张牌实际消耗一次才计一次。

| 缺口 | 组件 | 具体打法 |
| --- | --- | --- |
| 一张状态堵住循环 | 逆运经脉 | 1费选耗1张，固定抽3/4、运气1/2；若消耗的是状态牌再抽1张；本牌不自耗，后续轮次继续过滤。 |
| 多张废牌与当前来伤 | 内息归元 | 1费选耗至多3/4张；每张运气1、格挡2/3，本牌自耗。先保留必要的攻击与防守。 |
| 整手状态或残余废牌 | 生生不息 | 先打出当前要用的核心，再花2费获得6/8格挡，消耗全部其他手牌并转成等量随机剑气；本牌可循环。 |
| 多种状态混入抽牌 | 不染尘 | 清除虚弱、脆弱、中毒并获得7格挡，再消耗手中所有状态；每张回1气、抽1。保留普通好牌。 |
| 缺少当回合攻击 | 北冥借招 / 借招回锋 | 北冥借招为1费，生成2种不同原生外门攻击；借招回锋为2费攻击，先造成12/17点伤害，再借1张外门攻击并把异种真气加入手牌。借招池共23张，X费用外门牌仍保持X语义。 |
| 状态转化成当前行动 | 万流归宗 | X费一次获得4/6×X点格挡；按手牌顺序消耗至多X张状态，每张返1能量并运气1；不能用返还的能量重新计算X。 |
| 精确取回关键牌 | 回风取物 / 琅嬛寻卷 | 两者均1费消耗；前者从弃牌堆选择1张牌，后者从抽牌堆选择1张非状态牌。先取关键供气、格挡或攻击，再决定后续消耗。 |
| 持续状态燃料 | 经脉归一 | 3费能力，打出时及每回合开始加入异种真气；每回合前2次消耗状态牌后给5/7格挡、运气1并随机生成1张未升级剑气。 |

面对沙漏及 Wither 一类状态，先确认牌的原生回合末规则。需要使用的能力、供气或防守先打，再用生生不息换掉剩余手牌，避免把关键牌一起炼掉；只想清状态时用不染尘更精确。主动消耗能移除状态牌的后续手牌结算，单纯“这张牌自带消耗”不能替代清掉其他状态。非攻击状态伤害仍不能靠凌波减免。

气滞由蓄势一击加入弃牌堆，或由0费逆脉强攻直接加入手牌；若留在手中结束回合，先扣2气再虚无消耗，之后所有回合末收益完成再自然流失1气，两者都不算支付。异种真气由北冥借招加入弃牌堆，或由借招回锋与经脉归一直接加入手牌；1费换2气、1剑势、抽1并消耗。它是状态牌，不计技能。两者均不可升级，能作为主动消耗素材，状态清理也会消耗尚未打出的异种真气。

## 精简与混合

起手的基础牌先保留能撑过眼前路线的部分。已有更强输出后移除打击，已有稳定格挡后移除防御；不能先删尽防守，再期待奖励补齐。重复过渡牌会稀释神功、剑阵或抽牌核心，但牌数本身不是胜负标准。

北冥路线不能再依赖少泽剑气回能：当前六剑只提供伤害、减益、抽牌和关冲格挡。记诵剑谱与其他生成器的剑式由随机结果决定；凌波路线能用商阳、少商结束战斗；六脉路线仍需要吐纳、抱元守一这类独立有价值的技能。跨路线的单卡先看是否改善当前轮次，再看标签是否一致。

原生地图、旅行、商店、休息、事件、奖励和敌方回合均参与流程，A10难度与随机遗物正常生效；未追加属性、强制奖励或读档重试。两次均完成原生结局，`nativeEnded=true`、`winTime=8`、`remainingVictoryOptions=0`。最终首领战后生命为77/83；结局事件之后快照的0生命不代表战斗死亡。当时规则23/23、引擎235/235、资源116/116和86种卡牌数据校验通过。

通关构筑先用绵掌、探穴与基础耗气牌渡过第一幕，取得易经心法后建立持续格挡；第一首领奖励拿到六脉神剑，第二幕优先升级神剑与心法，第三幕补凌波微步、双脉并进、剑随心转与指法纯熟。最终32张牌包含2打击、4防御，并没有北冥神功或百川归海。这个例子说明混合构筑可以运作，不能证明32张是最佳牌数，或所有种子都能获得同样的核心。

本局也受益于原生Orobas事件的神剑附魔、磨刀石、准备背包、钢笔尖等随机收益，以及实际消耗的药水。最终首领第五回合用已积累的8层剑势衔接升级六剑，打到12层封顶；第二幕首领和最终首领战均保持入场生命。应把生成、持续格挡、虚弱、易伤、升级和遗物视作共同作用的结果，下一步仍需要多个独立种子和人工试玩评估强度。

后续平衡与持续回归重点：

- 玉佩是否只在战斗开始提供3真气，且不参与后续首技能、第三剑式和第六剑式奖励。
- 北冥神功的返气与回能、剑气抽牌和主动消耗组合是否出现非预期循环。
- 六脉神剑升级后的整套收益是否让其他稀有牌失去选择价值。
- 剑势每回合清零、群体伤害、Replay 与资源牌直接加层是否都遵守8层上限和每回合剑式门槛。
- 全程生命损失、卡牌升级与移除、药水使用、关键能力启动回合，以及第三幕连续首领的资源余量。
- 非攻击状态伤害、重复打出、同式升级与满手生成是否保持规则一致。
- 气滞扣气不计耗气，异种真气不计技能；主动消耗按实际成功张数计收益，不误耗本次新生成的剑。
- 14张改型攻击的目标、伤害与原有附效，以及北冥借招的白名单、临时费用、实例消耗和升级是否一致。
