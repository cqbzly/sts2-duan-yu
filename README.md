# 大理世子·段誉｜《杀戮尖塔2》角色模组

**不愿争胜，却身负绝学；以游身积气，以无形剑气破局。**

以金庸《天龙八部》的段誉为原型，设计一名通过技能蓄积真气、以凌波争取时间、用六脉剑气主动破局的角色。所有标注真气费用的牌都会在整张牌结算前检查并强制支付；真气不足时整张牌不可打出，不会出现只执行基础效果的半张牌。真气费用由专属费用标记显示，卡面正文不再重复“需N点真气”。

当前版本为 **v0.5.8 借招候选修正版**。本版修正借招候选：排除各角色打击及全部基础稀有度（Basic）攻击，其余攻击仍可出现。保留五张运转牌的重做：借力改为抽2/3弃1的技能，吐纳改为抽1并运气1/2，踏虚而行改为1层凌波加抽1/2，双脉并进改为从消耗堆取回至多1/2张剑气，一气贯之改为16/22伤害并抽2。撤回七张纯伤害牌在v0.5.6的削弱，北冥借招与借招回锋改从其他已注册角色完整卡池中的非基础稀有度攻击牌随机生成，高费及有专属资源门槛的攻击也能出现。百川归海基础和升级均为1费，产气2/3、回能1/2、抽2；玉佩开场3气，自己的回合结束失去1真气。开局4打击、4防御、北冥初窥与无意一指，共10张。真气使用独立图标与计数器，整张牌出牌前必须付足真气；能量免费不能免除真气，同次重放只支付一次。目标环境为《杀戮尖塔2》v0.113.1 public-beta 与 BaseLib 3.4.8；说明见[v0.5.8 更新记录](docs/releases/v0.5.8.md)。

v0.3.0 与 v0.4.0 的规则、引擎和单种子 A10 结果属于历史基线；当前版本的 A10 胜率仍需人工实机测试，不以自动策略模拟替代玩家通关。

## 安装与开发

玩家安装步骤见[安装说明](docs/installation.md)。模组只依赖 BaseLib，安装包包含 `CQBZLY_DUAN_YU.dll` 和对应JSON清单；图像与场景在本地生成并缓存，不需要额外下载资源或PCK。

开发需要 .NET 9 SDK，以及合法安装的目标版本游戏。仓库不包含游戏程序集。

```powershell
.\scripts\build.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
.\scripts\package.ps1 -Sts2Path 'D:\steam\steamapps\common\Slay the Spire 2'
```

源码位于 `src/DuanYu/`。构建默认不安装到游戏；安装脚本会备份同名旧模组文件。

## 核心机制

**北冥真气。** “运气N”增加真气，超过9点的部分丢失。六种剑气和所有标注真气费用的牌，都必须在出牌前足额支付；费用不足时整张牌不可打出，能量、手牌、伤害、格挡和计数均不改变。真气是段誉独立资源，与辉星完全分离；免费打出、自动打出和复制也不能免除真气费用。每个自己的回合结束，先完成回合末牌、气滞、虚无及相关消耗收益，再失去1点真气，最低为0；该流失不算支付，不触发返气和耗气奖励，敌方及队友回合不扣。

**凌波卸力。** 将要承受一段正数攻击伤害时，先消耗1层凌波，使修正后的伤害降低1点，然后结算格挡。多段攻击逐段处理；旧凌波在自己的下回合开始时清除。它是小幅缓冲，不能替代格挡。

**六脉变招。** 六种剑气各有分工，通用生成器使用战斗随机数无放回抽取，减少手动选牌和确定性循环。它们都是独立攻击牌，必须支付1点真气才能发动，不能仅靠生成就触发打牌收益。基础六剑如下，升级文本见图鉴。

**剑势成长。** 每张剑气实际结算后获得1层剑势；每回合首次打出第3种不同剑气额外获得1层，第6种额外获得1层。六种各打一次可从0升至8层，最高8层；每回合开始剑势清零，当前剑完成伤害后才增加剑势。每层为之后的剑气伤害加1，普通攻击不受影响。

**主动炼化。** 生生不息先获得6/8格挡，再消耗全部其他手牌，按实际数量生成随机剑气，允许重复；本牌不自耗，可以下一轮再用。逆运经脉单张消耗后固定抽牌，内息归元多张消耗换气与格挡，百脉归炉每次消耗补格挡；不染尘可集中清除手中状态牌。先打出想保留价值的核心，再清理状态与剩余废牌。

| 剑气 | 基础效果 |
| --- | --- |
| 少商剑气 | 需1点真气；造成7点伤害。 |
| 商阳剑气 | 需1点真气；造成3点伤害，给予目标1层易伤。 |
| 中冲剑气 | 需1点真气；对所有敌人造成5点伤害。 |
| 关冲剑气 | 需1点真气；造成3点伤害，获得3点格挡。 |
| 少冲剑气 | 需1点真气；造成2点伤害，抽1张牌。 |
| 少泽剑气 | 需1点真气；造成2点伤害，给予目标1层虚弱。 |

六剑均为0费、消耗、虚无，且每次发动支付1点真气。名称里的“剑气”与构筑标签不能混淆：规则中的剑气严格指这6种衍生牌。

## 卡池与构筑

常规奖励卡池由23张普通、38张罕见、22张稀有组成，其中攻击34张；这是本项目选定的设计规模，不是对官方角色卡池数量的断言。基础牌、六剑和两种状态牌不进入常规奖励、商店卡牌或随机变牌候选池。新增检索、X费用和状态联动牌仍按牌面规则结算。

- **北冥蓄势：** 吐纳、气海充盈积气，蓄势一击保留储备，以气催劲、天南一指兑现；不能一味等满气。
- **凌波游身：** 掠影步、倒踩七星、风过无痕稳定防守，回身一指与真气攻击结束战斗；多段减伤无法替代对重击的格挡。
- **六脉变招：** 记诵剑谱、剑随心转、无形剑阵生成剑气，双脉并进取回已消耗剑气，指法纯熟、六脉贯通奖励出牌；先施加易伤，再安排伤害与抽牌。
- **北冥炼化与借招：** 逆运经脉、内息归元、生生不息清理手牌；百脉归炉奖励消耗，北冥借招提供其他角色的攻击与后续异种真气；完整卡池和角色归属事件中的非基础攻击均可出现，也包含其他模组角色及注入牌；全部基础稀有度攻击和各角色打击均排除，候选数随启用内容变化。

书生意气为2费（升级1费），先抽2/3张，至少5气时再抽1，然后运气1、获得1层剑势；大梦初醒为1费，先清空格挡并抽3/4张，再运气2/3、获得1点能量和2/3层剑势。随机只决定生成的剑气或外门招式。气滞不可打出、虚无，留到回合末先扣2气；之后仍会结算额外的1气流失。异种真气为1费状态，运气2、剑势1、抽1、消耗。两种状态均不可升级。百脉归炉每次消耗给1/2格挡，消耗专属状态时额外运气1。

## 数据维护与校验

无需安装依赖，使用 Node.js 18 或更新版本。

```sh
node scripts/build-cards.mjs
node scripts/validate.mjs
```

`data/cards.json` 是卡牌文本的唯一数据源。第一条命令生成图鉴；第二条检查96种卡牌、稀有度分布、ID和名称唯一性、10张初始牌组、基础与升级文本、状态牌不可升级、剑气/状态生成引用以及生成文档一致性。人物、遗物、事件、规则和平衡文档由人工维护。

通过数据校验不等于通过实战平衡、联机同步或模组兼容性测试。当前卡池的回能、抽牌与回收组合仍需持续检查；规则、资源与引擎测试覆盖见[实现与测试记录](docs/implementation-and-testing.md)，完整 A10 流程结果见[完整流程验证](docs/full-run-validation.md)。
