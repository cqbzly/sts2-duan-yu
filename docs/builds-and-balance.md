# 段誉：构筑指南与平衡验证

版本0.1.0。本文给出可用于纸面推演、原型实现和后续游戏实测的起点。示例牌组不是固定通关配方；数值验算不构成胜率证据。

## 1. 设计取舍

段誉用一条主要资源轴“真气”支撑攻防，用最多3层的凌波争取积气时间，用六种剑气提供临场选择。没有额外加入六条经脉进度、随机走火入魔或抽到指定人物才能发动的条件。

北冥不直接吸血、不剥夺敌人回合；凌波不提供百分比无敌；六脉不要求集齐6张永久牌。代价主要落在能量、积气时间、手牌空间与出牌顺序上。角色没有卡牌直接提供能量，能量返还仅来自有限次数的专属遗物。

资源必须在初始牌组中就有出口，因此采用无意一指，而不是让前几场战斗只能积气。三条路线都能使用低稀有度牌起步，关键稀有牌改善上限，不应成为活过第一幕的前提。

## 2. 北冥蓄势

**循环：** 防御与运气 → 留住输出或抽到输出 → 决定留气打蓄势一击，还是支付真气爆发。

优先补充吐纳、以气催劲与抽牌。已有足够产气时，再选气海充盈往往不如获得可靠的输出或防御；满气回合继续运气会浪费牌与费用。天南一指是终结奖励，不是每回合都要满足的目标。

### 18张示例牌组

| 牌 | 张数 | 任务 |
| --- | --- | --- |
| 打击 | 2 | 早期过渡，后续移除候选。 |
| 防御 | 3 | 基础防守。 |
| 北冥初窥 / 凌波初步 / 无意一指 | 各1 | 保留初始资源教学和基础兑现。 |
| 吐纳 | 2 | 积气与防御。 |
| 气海充盈 | 1 | 一次性加速。 |
| 以气催劲 / 蓄势一击 | 各1 | 分别承担花气与留气的攻击。 |
| 书生意气 / 袖底藏锋 | 各1 | 调整手牌与出手机会。 |
| 抱元守一 | 1 | 将储备转为紧急格挡。 |
| 北冥初成 | 1 | 有限次数的抽牌引擎。 |
| 天南一指 | 1 | 满气时的终结牌。 |

没有天南一指时可用第二张以气催劲；没有北冥初成时可用读书明理。升级优先考虑以气催劲、北冥初窥与经常需要保血的牌。袖底藏锋降费后适合在同回合整理与爆发，但它仍占用一张抽牌。

**危险对局：** 前几回合施加强压、持续堆高攻击、频繁塞状态牌的敌人。应主动用气保血，不能为等到9气而连续吃伤害。

## 3. 凌波游身

**循环：** 预先获得凌波 → 用格挡处理剩余伤害 → 通过回身一指和耗气攻击结束战斗。

凌波是在三段攻击上分别减3，不是本回合所有攻击都减3。对单次大攻击，继续堆第2、第3层没有当下收益；应选择抱元守一或更多直接格挡。虚弱、格挡与凌波相互补充，但不能抵抗直接失去生命。

### 18张示例牌组

| 牌 | 张数 | 任务 |
| --- | --- | --- |
| 打击 | 1 | 过渡。 |
| 防御 | 3 | 基础防守。 |
| 北冥初窥 / 凌波初步 / 无意一指 | 各1 | 产气与攻击出口。 |
| 回身一指 | 2 | 借已有步法兼顾攻防。 |
| 掠影步 | 2 | 稳定取得凌波与格挡。 |
| 倒踩七星 / 风过无痕 / 斜行避势 | 各1 | 下轮手牌、受击后防守、虚弱。 |
| 抱元守一 / 气贯长虹 | 各1 | 紧急防御与群体输出。 |
| 凌波微步 / 以气催劲 | 各1 | 持续步法与主动收尾。 |

没有凌波微步时用借隙回身或逍遥游步。优先升级掠影步、回身一指，再考虑凌波微步降费。每回合最多3层的限制意味着重复的步法牌并非越多越好。

**危险对局：** 单次重击、非攻击生命损失与无限成长敌人。牌组必须保留输出；不争之心与枯荣禅珠补偿准备回合，不应引导每回合完全不攻击。

## 4. 六脉变招

**循环：** 按敌人选择生成器 → 先铺易伤或弱化 → 用剑气伤害、抽牌、格挡衔接下一张牌。

面对群敌选中冲；准备集中输出先选商阳；需要防守选关冲或少泽；手牌不足且还有能量时选少冲。少商用于直接兑现，不必为了凑第3种而生成当前完全无用的剑气。

### 18张示例牌组

| 牌 | 张数 | 任务 |
| --- | --- | --- |
| 打击 | 1 | 过渡。 |
| 防御 | 3 | 基础防守。 |
| 北冥初窥 / 凌波初步 / 无意一指 | 各1 | 初始产气、步法与气的出口。 |
| 记诵剑谱 | 2 | 自由选剑，升级保持1费。 |
| 少商起势 / 商阳点穴 / 少冲探路 | 各1 | 日常伤害、减益和抽牌。 |
| 双脉并进 / 凝气成锋 / 指法纯熟 | 各1 | 一次性变招与伤害增强。 |
| 六脉贯通 / 六脉神剑 / 吐纳 | 各1 | 有限抽牌返气、大回合与产气。 |

没有六脉神剑时用双脉并进或中冲破阵；没有六脉贯通时补少冲探路或读书明理。优先升级记诵剑谱、商阳点穴；已经能稳定提供6气时，再优先降低六脉神剑费用。

**危险对局：** 惩罚高出牌次数、攻击触发反伤、大量塞牌限制手牌空间的敌人。六张0费剑气仍是六次实际攻击；不能把它们当作一次不受反制的大招。

## 5. 三个纸面回合

以下均假设没有力量、敏捷、额外遗物和能力干扰，目标存活到本回合结束。易伤按常规1.5倍并向下取整示例计算，最终实现需核对目标版本的宿主取整规则。

### 入门：积气同时防守

战斗开始真气2，能量3，手中有北冥初窥、凌波初步、无意一指。

1. 北冥初窥：4格挡，真气2→4；玉佩在技能结算后使真气4→5。
2. 凌波初步：再得5格挡与1层凌波，真气仍为5。
3. 无意一指：6伤害，耗气2再6伤害，真气5→3。

合计12伤害、9格挡、1层凌波、剩余真气3。随后若受到单次12点攻击，先由凌波减至9，再由格挡全部吸收。

### 游身：防守后主动结束战斗

当前真气3、能量3，依次打出掠影步+、回身一指+、以气催劲。

1. 掠影步+：12格挡、2层凌波；本回合首技能触发玉佩，真气3→4。
2. 回身一指+：10伤害；因拥有凌波，再得7格挡。
3. 以气催劲：12伤害，耗气3再12伤害，真气4→1。

合计34伤害、19格挡、2层凌波、剩余真气1。下一次20点重击只消耗1层凌波，变为17点，19格挡可以完全抵消。剩余凌波不会自动转为下回合资源。

### 六脉：先铺气劲，再依次选招

当前真气6、能量3，手中5张牌包含凝气成锋与六脉神剑+。本回合尚未打技能，目标无格挡和减益。

1. 凝气成锋花1能量：运气1，再由玉佩运气1，真气6→8；本回合剑气伤害+2。
2. 六脉神剑+花2能量：12格挡，耗气6，真气8→2；生成六剑。此时原手牌剩3张，六剑全部入手，合计9张。
3. 先打商阳：4+2=6伤害，然后施加1层易伤。
4. 再打少商、中冲、关冲、少冲、少泽：在该目标上分别造成13、10、9、7、7伤害。

对同一目标合计52伤害，另有16格挡、1次抽牌、1层虚弱，真气剩2。中冲也伤害其他敌人；少泽在伤害后才施加虚弱。此例需要积气、两张指定手牌和六脉神剑升级，不能当作每回合的稳定输出承诺。

## 6. 数值边界与风险

- **起始遗物已经有价值。** 初始2气可让无意一指多造成6伤害，之后每回合首个技能再供1气。评估卡牌时需要计入这部分持续供给。
- **1气没有固定金币式估值。** 无意一指以2气换6额外伤害，抱元守一以2气换7额外格挡；需求和出牌时机不同。9气的存储上限压缩等待收益。
- **凌波的每段减伤固定。** 一次重击只减少3；至少三段有效攻击才能用满3层的9点减伤。提高层数或允许敏捷增加减伤都会破坏当前定位，本版不提供这种效果。
- **真气护体有明确上限。** 满9气时每层基础能力提供4格挡，升级提供6；多层数值相加。它提供留气的理由，但仍需警惕无输出的拖延牌组。
- **生成器也有成本。** 剑气虽0费，生成技能仍支付费用、消耗抽牌与手牌空间；少冲剑气的抽牌使它尤其容易成为循环节点。
- **有限触发不能替代循环审计。** 北冥神功、六脉贯通、六脉图谱都有次数限制，但生成器自身仍可能循环，必须检查完整的抽牌与回收路径。
- **多人支援不复制资源。** 援手只为打出者运气，格挡归所选接收者；同行只让接收者抽牌。队友行动不能让个人次数重置。

## 8. 实现后的测试计划

### 机制验收

逐项运行[机制验收例](mechanics.md#9-验收例)，再覆盖以下组合：

- 耗气失败仍消耗；耗气到0后返气仍触发国印；已满气时玉佩次数仍用掉。
- 风过无痕的格挡发生在该段伤害之后，不能回溯；多段攻击的后续段可以使用新格挡。
- 能力在第3张技能后才获得，不重新得到“前2张”名额；同名多层提升数值但不扩次数。
- 满手生成、主动丢弃、保留与虚无、升级已有升级牌、消耗堆取回，以及少冲抽牌触发洗牌。
- 生生不息不能选择其自身ID的升级版或复制牌；剑随心转无剑气可空放，不能空手生成。
- 多人同时攻击同一敌人、援助已结束行动的队友、施术者自伤死亡、多人共享玩家阶段只重置一次。
- 与宿主的免费出牌、自动重打、复制、消耗触发、额外抽牌、力量、多段强化、减益防护逐类组合。

### 游戏实测

先以无额外难度的单人模式进行至少30局探索测试，覆盖三条路线与混合构筑；再用固定种子成对比较改动前后的关键对局。30局只用于发现明显问题，不能支撑精确胜率结论。之后扩大样本并覆盖较高难度、不同人数和队伍组合。

记录每战生命损失、回合数、真气获得／溢出／支付、凌波获得／实际减伤／过期、剑气生成／打出／溢出、手牌堵塞次数、能力安装回合和战斗结束时未兑现的资源。每张牌记录拿取与跳过、升级选择、上手后实际打出及其带来的收益。

测试至少包含四类情境：前两轮高压、连续多段小攻击、单次重击、持续成长／惩罚高出牌数。敌人的具体选择与难度版本在实现后记录，不把虚构对局当作实际游戏数据。

### 调整顺序

1. 先修确定性漏洞、文字歧义与无限循环。
2. 若角色开局普遍掉血过多，先检查产气与基础输出的抽取顺序，再调整基础防御，不直接给持续治疗。
3. 若北冥路线过强，先调整耗气收益、一次性加速或被动防守；不要同时更改真气上限与全部产气量。
4. 若凌波过强，先核查每段正确消耗、层数上限及状态持续时间，再调整获得层数或牌费用。
5. 若六脉过强，优先检查少冲循环、易伤前置、免费生成和多层能力；不要仅增加无关牌的费用。
6. 每次记录一个主要改动及理由，重新验证数据与关键回归情境，再扩大测试。

## 9. 后续模组开发范围

当前仓库已提供稳定卡牌ID、完整文本和行为规则。实施时仍需要针对具体游戏版本确认角色注册、资源状态、卡牌生成、目标选择、回合事件、联机同步与本地化接口；此处不虚构API名称。

建议先实现5种基础牌、初始遗物和真气／凌波的最小战斗原型，再实现6种剑气与少量生成器，完成上述边界验收后扩展至全卡池。最后接入8件遗物、2事件和视听资源，并分别记录单人与联机验证结果。
